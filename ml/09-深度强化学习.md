## 1. 强化学习解决什么问题

强化学习研究的是智能体如何通过和环境交互来学习策略。

和监督学习不同，强化学习不是直接给出每一步的标准答案，而是给出动作之后的奖励。智能体需要根据长期累计奖励来判断当前动作好不好。

典型例子：

- 游戏智能体根据当前画面选择下一步操作。
- 机器人根据传感器状态选择移动方向。
- 自动控制系统根据设备状态选择控制动作。

## 2. 基本要素

| 概念 | 说明 |
| --- | --- |
| Agent | 智能体，负责感知状态、选择动作、学习策略 |
| Environment | 环境，会根据智能体动作改变状态并返回奖励 |
| State | 状态，记作 `s`，表示当前环境信息 |
| Action | 动作，记作 `a`，表示智能体可执行的选择 |
| Reward | 奖励，记作 `r`，表示环境对动作结果的反馈 |
| Policy | 策略，记作 `π(a|s)`，表示在状态 `s` 下选择动作 `a` 的概率 |
| Transition | 状态转移，记作 `p(s'|s,a)`，表示执行动作后转到新状态的概率 |

强化学习的核心循环：

```text
Agent 观察状态 s
-> 根据策略 π(a|s) 选择动作 a
-> Environment 返回奖励 r 和新状态 s'
-> Agent 根据经验更新策略
```

## 3. 马尔可夫决策过程

强化学习常用马尔可夫决策过程（Markov Decision Process, MDP）描述。

MDP 通常由下面几个部分组成：

```text
(S, A, P, R, gamma)
```

- `S`：状态集合。
- `A`：动作集合。
- `P`：状态转移概率。
- `R`：奖励函数。
- `gamma`：折扣因子。

马尔可夫性指的是：下一状态只依赖当前状态和当前动作，不依赖更早的历史。

$$
P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots) = P(s_{t+1} \mid s_t, a_t)
$$

## 4. 轨迹、策略和回报

一次完整交互过程可以看作轨迹：

```text
tau = (s0, a0, r1, s1, a1, r2, ..., sT)
```

策略表示状态到动作的选择规则：

$$
\pi(a \mid s) = P(a_t = a \mid s_t = s)
$$

回报（return）表示从某一时刻开始获得的累计奖励。为了让远期奖励影响变小，通常引入折扣因子 `gamma`。

$$
G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots
$$

`gamma` 越接近 0，智能体越重视短期奖励；`gamma` 越接近 1，智能体越重视长期奖励。

强化学习的目标是找到一个策略，使期望回报最大：

$$
J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}[G(\tau)]
$$

## 5. 值函数

值函数用于评估一个策略好不好。

状态值函数表示：从状态 `s` 开始，按照策略 `π` 行动，未来能获得的期望回报。

$$
V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]
$$

状态-动作值函数，也叫 Q 函数，表示：在状态 `s` 下先执行动作 `a`，之后按照策略 `π` 行动，未来能获得的期望回报。

$$
Q^\pi(s,a) = \mathbb{E}_\pi[G_t \mid s_t = s, a_t = a]
$$

直观理解：

- `V(s)` 问的是：这个状态本身有多好？
- `Q(s,a)` 问的是：在这个状态下做这个动作有多好？

## 6. Bellman 方程

Bellman 方程把“当前奖励”和“未来价值”联系起来。

状态值函数的 Bellman 形式：

$$
V^\pi(s) =
\sum_a \pi(a \mid s)
\sum_{s'} P(s' \mid s,a)
\left[
R(s,a,s') + \gamma V^\pi(s')
\right]
$$

Q 函数的 Bellman 形式：

$$
Q^\pi(s,a) =
\sum_{s'} P(s' \mid s,a)
\left[
R(s,a,s') + \gamma \sum_{a'} \pi(a' \mid s') Q^\pi(s',a')
\right]
$$

学习值函数，本质上就是让当前估计逐步满足 Bellman 方程。

## 7. 最优策略与策略改进

最优策略记作 `π*`，它在所有状态上都能取得最大期望回报。

$$
\pi^* = \arg\max_\pi V^\pi(s)
$$

如果在某个状态 `s` 下，有一个动作 `a` 的 Q 值高于当前策略的平均表现，就应该提高选择该动作的概率。

常见的策略改进方式是贪心选择：

$$
\pi(s) = \arg\max_a Q(s,a)
$$

但只贪心会导致探索不足，所以常用 `epsilon-greedy`：

- 以 `1 - epsilon` 的概率选择当前最优动作。
- 以 `epsilon` 的概率随机探索其他动作。

## 8. 基于模型和模型无关方法

强化学习算法可以分成两类。

基于模型的方法：

- 已知或学习环境模型 `P(s'|s,a)` 和 `R(s,a,s')`。
- 典型方法：策略迭代、值迭代。

模型无关的方法：

- 不需要显式知道状态转移概率。
- 直接通过采样经验学习价值或策略。
- 典型方法：蒙特卡罗、时序差分、SARSA、Q-learning。

## 9. 蒙特卡罗和时序差分

蒙特卡罗方法用一整条轨迹结束后的真实回报来估计价值。

优点是估计目标直观；缺点是必须等 episode 结束，方差较大。

时序差分（Temporal Difference, TD）不需要等完整轨迹结束，而是用当前奖励加下一状态估计值作为目标。

TD 目标：

$$
r_{t+1} + \gamma V(s_{t+1})
$$

TD 误差：

$$
\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)
$$

TD 方法结合了动态规划和蒙特卡罗思想。

## 10. SARSA

SARSA 是一种 on-policy 方法，名字来自一次更新需要的五元组：

```text
State, Action, Reward, State, Action
```

更新公式：

$$
Q(s_t,a_t) \leftarrow Q(s_t,a_t) +
\alpha
\left[
r_{t+1} + \gamma Q(s_{t+1},a_{t+1}) - Q(s_t,a_t)
\right]
$$

SARSA 使用当前策略实际选择的下一个动作 `a_{t+1}` 来更新，因此它学习的是当前行为策略本身。

## 11. Q-learning

Q-learning 是一种 off-policy 方法。它不使用当前策略实际选出来的下一个动作，而是假设下一步选择最优动作。

更新公式：

$$
Q(s_t,a_t) \leftarrow Q(s_t,a_t) +
\alpha
\left[
r_{t+1} + \gamma \max_{a'} Q(s_{t+1},a') - Q(s_t,a_t)
\right]
$$

SARSA 更保守，因为它考虑当前探索策略的风险；Q-learning 更激进，因为它直接朝最优 Q 函数学习。

## 12. 深度强化学习

当状态空间很大或连续时，不能再用表格存储 `Q(s,a)`。深度强化学习使用神经网络近似值函数或策略。

深度强化学习可以理解为：

```text
强化学习定义问题和优化目标
深度学习负责表示状态、值函数或策略
```

用神经网络近似 Q 函数：

$$
Q_\phi(s,a) \approx Q(s,a)
$$

其中 `phi` 是神经网络参数。

## 13. DQN

DQN（Deep Q-Network）用神经网络表示 Q 函数，是基于值函数的深度强化学习方法。

DQN 解决两个主要问题：

1. 学习目标不稳定：目标值依赖正在更新的网络参数。
2. 样本相关性强：连续采样得到的状态高度相关。

DQN 的两个关键技巧：

- 目标网络（target network）：固定一段时间的目标 Q 网络参数，让训练目标更稳定。
- 经验回放（experience replay）：把交互经验放进经验池，训练时随机采样，降低样本相关性。

DQN 的目标值通常写作：

$$
y = r + \gamma \max_{a'} Q_{\phi^-}(s', a')
$$

其中 `phi^-` 表示目标网络参数。

训练损失：

$$
L(\phi) =
\left[
y - Q_\phi(s,a)
\right]^2
$$

## 14. AlphaGo 中的思想

AlphaGo 把监督学习、强化学习、价值网络、策略网络和蒙特卡罗树搜索结合起来。

可以粗略理解为：

- 策略网络：给出更值得搜索的动作。
- 价值网络：评估当前局面的长期价值。
- MCTS：在有限搜索空间里模拟未来走势。
- 强化学习：通过自我对弈继续提升策略。

这一部分不是入门强化学习的核心公式，但能帮助理解深度强化学习如何解决复杂决策问题。

## 15. 常见超参数

| 参数 | 含义 | 影响 |
| --- | --- | --- |
| `gamma` | 折扣因子 | 控制短期奖励和长期奖励的权衡 |
| `alpha` | 学习率 | 控制每次更新的幅度 |
| `epsilon` | 探索概率 | 控制探索和利用的比例 |
| `replay_size` | 经验池大小 | 影响样本多样性和内存占用 |
| `batch_size` | 批大小 | 影响训练稳定性和速度 |
| `target_update` | 目标网络更新频率 | 影响目标稳定性 |

## 16. 记忆重点

- 强化学习关注的是序列决策和长期回报。
- MDP 是强化学习最常见的数学描述。
- 策略 `π(a|s)` 决定智能体如何行动。
- 值函数 `V(s)` 和 Q 函数 `Q(s,a)` 用来评价状态或动作。
- Bellman 方程把当前奖励和未来价值联系起来。
- SARSA 是 on-policy，Q-learning 是 off-policy。
- DQN 用神经网络近似 Q 函数，并依靠目标网络和经验回放稳定训练。
