# 基础概念与学习流程

## 1. 什么是机器学习

机器学习是让计算机从数据中学习规律，并用这些规律对未知样本进行预测、分类、聚类或决策的方法。

传统编程：

```text
规则 + 数据 -> 结果
```

机器学习：

```text
数据 + 结果 -> 规则/模型
```

模型训练完成后：

```text
新数据 + 模型 -> 预测结果
```

## 2. 机器学习的主要类型

### 2.1 监督学习

数据包含标签，模型学习输入 X 到输出 y 的映射。

常见任务：

- 分类：输出离散类别，如猫/狗、正常/异常。
- 回归：输出连续数值，如房价、温度、销量。

典型算法：

- 线性回归
- 逻辑回归
- KNN
- 决策树
- 随机森林
- GBDT、XGBoost、LightGBM
- SVM
- 神经网络

### 2.2 无监督学习

数据没有标签，模型从数据中发现结构。

常见任务：

- 聚类：把相似样本分到同一类。
- 降维：把高维数据压缩到低维。
- 异常检测：找出和大多数样本不同的数据。

典型算法：

- K-Means
- DBSCAN
- 层次聚类
- PCA
- AutoEncoder

### 2.3 半监督学习

同时使用少量有标签数据和大量无标签数据。适合标注成本高、原始数据多的场景。

### 2.4 强化学习

智能体通过和环境交互获得奖励，并学习让长期奖励最大的策略。

关键词：

- Agent：智能体
- Environment：环境
- State：状态
- Action：动作
- Reward：奖励
- Policy：策略

## 3. 训练集、验证集、测试集

### 3.1 训练集

用于训练模型参数。

### 3.2 验证集

用于选择模型和调参。

### 3.3 测试集

用于最终评估模型泛化能力。测试集不应该参与调参。

常见划分：

```text
训练集 70% / 验证集 15% / 测试集 15%
训练集 80% / 测试集 20%
```

时间序列数据要按时间切分，不能随机打乱。

## 4. 模型、参数和超参数

### 4.1 参数

模型训练过程中自动学习到的值。

例子：

- 线性回归中的权重 w 和偏置 b。
- 神经网络中的权重矩阵。

### 4.2 超参数

训练前人为设定的值。

例子：

- 学习率
- 决策树最大深度
- KNN 的 K
- SVM 的 C 和 gamma
- 神经网络层数
- batch size

## 5. 损失函数

损失函数用于衡量模型预测值和真实值之间的差距。

常见损失：

- 回归：MSE、MAE、Huber Loss。
- 二分类：Binary Cross Entropy。
- 多分类：Cross Entropy。

训练模型的目标就是让损失尽可能小。

## 6. 优化

优化器负责更新模型参数，使损失函数下降。

常见优化器：

- Gradient Descent
- SGD
- Momentum
- RMSProp
- Adam
- AdamW

基础更新形式：

```text
参数 = 参数 - 学习率 * 梯度
```

## 7. 过拟合与欠拟合

### 7.1 欠拟合

模型太简单，没有学到数据中的规律。

表现：

- 训练集效果差。
- 测试集效果也差。

解决方法：

- 增加模型复杂度。
- 增加有效特征。
- 减少正则化。
- 训练更久。

### 7.2 过拟合

模型把训练数据中的噪声也学进去了，泛化能力差。

表现：

- 训练集效果很好。
- 验证集或测试集效果明显变差。

解决方法：

- 增加数据量。
- 使用数据增强。
- 减小模型复杂度。
- 加强正则化。
- 使用 Dropout。
- 使用 Early Stopping。
- 做交叉验证。

## 8. 数据泄漏

数据泄漏是指训练过程中使用了真实预测场景中无法获得的信息，导致离线评估虚高。

常见情况：

- 用未来数据预测过去。
- 特征中直接包含标签。
- 先在全量数据上标准化，再划分训练集和测试集。
- 同一个用户或设备的数据同时出现在训练集和测试集。

避免方法：

- 先划分数据集，再 fit 预处理器。
- 使用 Pipeline。
- 时间数据按时间切分。
- 用户、设备、订单等实体做分组切分。

## 9. 一个标准机器学习项目流程

```text
明确问题
-> 明确评价指标
-> 收集数据
-> 清洗数据
-> 特征工程
-> 划分数据集
-> 建立基线模型
-> 训练和调参
-> 测试集最终评估
-> 部署上线
-> 监控和迭代
```

## 10. 基线模型

基线模型是第一个简单可运行的模型，用来判断问题和数据是否有学习价值。

常见基线：

- 分类：多数类预测、逻辑回归、决策树。
- 回归：均值预测、线性回归。
- 图像：简单 CNN。
- 文本：TF-IDF + 逻辑回归。

基线模型不一定效果最好，但能快速暴露数据、标签和流程问题。
