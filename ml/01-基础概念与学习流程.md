# 基础概念与学习流程

## 学习法小结

这一章不要急着背模型名，先建立机器学习的整体框架。

学习顺序：

1. 先分清 `数据`、`特征`、`标签`、`模型`、`算法`。
2. 再分清监督学习、无监督学习、半监督学习、强化学习。
3. 最后把训练集、验证集、测试集和完整项目流程串起来。

最小掌握目标：

- 能用一句话解释机器学习和传统编程的区别。
- 能判断一个任务属于分类、回归、聚类还是决策问题。
- 能说清楚训练、验证、测试分别在什么时候用。

自测问题：

- 如果输入是房屋面积，输出是房价，这是什么任务？
- 如果只有用户行为数据，没有用户标签，这是什么任务？
- 为什么测试集不能反复拿来调参？

## 1. 什么是机器学习

机器学习是让计算机从数据中学习规律，并用这些规律对未知样本进行预测、分类、聚类或决策的方法。

例子：
给模型一批房屋特征，如面积、楼层、地段，再给它对应成交价，模型就会学习“什么样的房子大概值多少钱”。给模型一批邮件文本和“垃圾邮件/正常邮件”标签，模型就会学习“什么样的词更像垃圾邮件”。

传统编程：

```text
规则 + 数据 -> 结果
```

机器学习：

```text
数据 + 结果 -> 规则/模型
```

模型训练完成后：

```text
新数据 + 模型 -> 预测结果
```

## 2. 机器学习的主要类型

### 2.1 监督学习

数据包含标签，模型学习输入 `X` 到输出 `y` 的映射。

常见任务：

- 分类：输出离散类别，如猫/狗、正常/异常。
- 回归：输出连续数值，如房价、温度、销量。

例子：
做垃圾邮件识别时，输入是邮件文本，输出是“垃圾”或“正常”，这是分类。做房价预测时，输入是面积、地段、楼龄，输出是具体价格，这是回归。

典型算法：

- 线性回归
- 逻辑回归
- KNN
- 决策树
- 随机森林
- GBDT、XGBoost、LightGBM
- SVM
- 神经网络

### 2.2 无监督学习

数据没有标签，模型从数据中发现结构。

常见任务：

- 聚类：把相似样本分到同一类。
- 降维：把高维数据压缩到低维。
- 异常检测：找出和大多数样本不同的数据。

典型算法：

- K-Means
- DBSCAN
- 层次聚类
- PCA
- AutoEncoder

例子：
商场只有用户购买记录，没有“高价值用户”标签，这时可以先做聚类，把用户自动分成“高频低价”“低频高价”“沉睡用户”等群体。

### 2.3 半监督学习

同时使用少量有标签数据和大量无标签数据。适合标注成本高、原始数据多的场景。

例子：
你有 2000 张工业缺陷图片，但只有 100 张人工标了“正常/裂纹/污染”。这时可以用这 100 张有标签图加上剩余 1900 张无标签图一起训练。

### 2.4 强化学习

智能体通过和环境交互获得奖励，并学习让长期奖励最大的策略。

关键词：

- Agent：智能体
- Environment：环境
- State：状态
- Action：动作
- Reward：奖励
- Policy：策略

例子：
训练一个下棋程序时，每走一步棋都会影响后续局面。赢棋得到高奖励，输棋得到低奖励，模型会逐步学会让长期总奖励更高的走法。

## 3. 训练集、验证集、测试集

### 3.1 训练集

用于训练模型参数。

### 3.2 验证集

用于选择模型和调参。

### 3.3 测试集

用于最终评估模型泛化能力。测试集不应该参与调参。

常见划分：

```text
训练集 70% / 验证集 15% / 测试集 15%
训练集 80% / 测试集 20%
```

时间序列数据要按时间切分，不能随机打乱。

例子：
如果你有 10000 条订单数据，可以拿前 7000 条训练、1500 条验证、1500 条测试。要是这些订单带时间顺序，比如 1 到 12 月销售额，就应该用前几个月训练，后几个月验证和测试，不能打乱。

## 4. 模型、参数和超参数

### 4.1 参数

模型训练过程中自动学习到的值。

例子：

- 线性回归中的权重 w 和偏置 b。
- 神经网络中的权重矩阵。

直觉理解：
参数是模型自己在训练里学出来的答案。比如线性回归最后学到“面积每增加 1 平方米，房价平均增加 1.2 万元”，这里的 `1.2` 就是参数的一部分。

### 4.2 超参数

训练前人为设定的值。

例子：

- 学习率
- 决策树最大深度
- KNN 的 K
- SVM 的 C 和 gamma
- 神经网络层数
- batch size

直觉理解：
超参数像做菜前要先定好的火候和时间。比如同样是 KNN，`K=3` 和 `K=15` 会得到完全不同的决策边界，但这个 `K` 不是模型自己学出来的，而是你先设定的。

## 5. 损失函数

损失函数用于衡量模型预测值和真实值之间的差距。

常见损失：

- 回归：MSE、MAE、Huber Loss。
- 二分类：Binary Cross Entropy。
- 多分类：Cross Entropy。

训练模型的目标就是让损失尽可能小。

常见公式：

$$
\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2
$$

$$
\mathrm{BCE} = -\frac{1}{n}\sum_{i=1}^{n}\left[y_i\log \hat{p}_i + (1-y_i)\log(1-\hat{p}_i)\right]
$$

例子：
房价真实值是 300 万，模型预测成 260 万，损失就会比较大。垃圾邮件任务里，真实标签是 1，但模型只给出 0.1 的垃圾概率，也会产生较大交叉熵损失。

## 6. 优化

优化器负责更新模型参数，使损失函数下降。

常见优化器：

- Gradient Descent
- SGD
- Momentum
- RMSProp
- Adam
- AdamW

基础更新形式：

$$
\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}
$$

其中 `theta` 是参数，`eta` 是学习率，`L` 是损失函数。

例子：
如果模型总把房价预测得偏高，梯度会告诉你“哪些权重该减小”。优化器每一步都沿着让损失下降的方向微调参数。

## 7. 过拟合与欠拟合

### 7.1 欠拟合

模型太简单，没有学到数据中的规律。

表现：

- 训练集效果差。
- 测试集效果也差。

解决方法：

- 增加模型复杂度。
- 增加有效特征。
- 减少正则化。
- 训练更久。

例子：
如果你只用“房屋面积”一个特征去预测复杂城市里的房价，模型可能连学区、地段差异都表达不出来，这就是欠拟合。

### 7.2 过拟合

模型把训练数据中的噪声也学进去了，泛化能力差。

表现：

- 训练集效果很好。
- 验证集或测试集效果明显变差。

解决方法：

- 增加数据量。
- 使用数据增强。
- 减小模型复杂度。
- 加强正则化。
- 使用 Dropout。
- 使用 Early Stopping。
- 做交叉验证。

例子：
如果一个很深的树模型把训练集里每个小区、每条街道都记住了，训练集准确率很高，但换个新区数据就崩，这就是过拟合。

## 8. 数据泄漏

数据泄漏是指训练过程中使用了真实预测场景中无法获得的信息，导致离线评估虚高。

常见情况：

- 用未来数据预测过去。
- 特征中直接包含标签。
- 先在全量数据上标准化，再划分训练集和测试集。
- 同一个用户或设备的数据同时出现在训练集和测试集。

避免方法：

- 先划分数据集，再 fit 预处理器。
- 使用 Pipeline。
- 时间数据按时间切分。
- 用户、设备、订单等实体做分组切分。

例子：
做“用户是否会逾期”预测时，如果特征里放了“催收次数”，而这个字段只有逾期后才会产生，那模型就是偷看了未来信息。

## 9. 一个标准机器学习项目流程

```text
明确问题
-> 明确评价指标
-> 收集数据
-> 清洗数据
-> 特征工程
-> 划分数据集
-> 建立基线模型
-> 训练和调参
-> 测试集最终评估
-> 部署上线
-> 监控和迭代
```

例子：
做二手车价格预测时，流程可以理解成：先确定目标是预测成交价，再收集车辆年份、里程、品牌等数据，清洗异常值，训练一个线性回归当基线，然后再尝试树模型和集成模型。

## 10. 基线模型

基线模型是第一个简单可运行的模型，用来判断问题和数据是否有学习价值。

常见基线：

- 分类：多数类预测、逻辑回归、决策树。
- 回归：均值预测、线性回归。
- 图像：简单 CNN。
- 文本：TF-IDF + 逻辑回归。

基线模型不一定效果最好，但能快速暴露数据、标签和流程问题。

例子：
做文本情感分类时，先跑一个 `TF-IDF + LogisticRegression`。如果这个简单模型已经有 88% 准确率，那你后面上 Transformer 时就知道自己到底提升了多少，而不是盲目觉得“深模型一定更好”。
