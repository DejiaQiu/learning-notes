## 4. 常见任务与模型选择

| 任务 | 常见模型 | 说明 |
| --- | --- | --- |
| 表格分类 | 逻辑回归、随机森林、XGBoost、LightGBM | 先做简单基线，再尝试树模型 |
| 表格回归 | 线性回归、随机森林、GBDT | 注意异常值和特征尺度 |
| 文本分类 | TF-IDF + 线性模型、Transformer | 小数据可先用传统方法 |
| 图像分类 | CNN、ResNet、ViT | CNN 是基础，池化和卷积必须掌握 |
| 聚类分群 | K-Means、DBSCAN、层次聚类 | 聚类前通常需要标准化 |
| 降维可视化 | PCA、t-SNE、UMAP | PCA 适合理解方差，t-SNE/UMAP 适合可视化 |
| 异常检测 | Isolation Forest、One-Class SVM、AutoEncoder | 评估指标要结合业务代价 |

## 5. 学习时要重点掌握的问题

- 这个模型解决什么任务？
- 模型的核心假设是什么？
- 损失函数是什么？
- 训练时优化的目标是什么？
- 容易过拟合还是欠拟合？
- 对特征缩放是否敏感？
- 优缺点分别是什么？
- 适合什么数据，不适合什么数据？
- 如何解释模型结果？
- 常见参数如何影响模型表现？

## 6. 重要原则

- 先建立简单基线，不要一开始就上复杂模型。
- 数据质量通常比模型复杂度更重要。
- 测试集只用于最终评估，不要反复用测试集调参。
- 对类别不平衡问题，不能只看 Accuracy。
- 预处理要放进 Pipeline，减少数据泄漏。
- 时间序列数据不要随机打乱。
- 模型上线后要监控数据分布变化和预测结果变化。

## 7. 研究生论文需要额外掌握的内容

如果目标是支撑研究生论文，不需要把所有算法都背完，但需要能完成以下工作：

- 能说明方法的理论基础，例如损失函数、优化目标、概率假设。
- 能选择合理 baseline，并解释为什么选这些模型。
- 能设计对比实验、消融实验和参数敏感性实验。
- 能用合适指标评价模型，而不是只报告 Accuracy。
- 能解释模型为什么有效，例如特征重要性、注意力可视化、错误案例分析。
- 能保证实验可复现，包括数据划分、随机种子、环境版本、超参数。
- 能写清楚研究问题、方法创新点、实验结果和局限性。
