# Machine Learning 学习笔记目录

这个目录按课件 PDF 的章节重新整理。主线以“第 1 章到第 10 章”为准，其他原有笔记作为补充材料保留，不强行重命名文件。

笔记统一使用下面的写法：

- 先看“这个问题是什么”，再看“核心公式怎么来”，最后看“真实任务里怎么用”。
- 公式尽量用独立 LaTeX 块。变量说明、小表达式用代码样式，避免 Markdown 显示异常。
- 每章都要能回答：模型假设是什么、优化目标是什么、适合什么数据、常见缺点是什么。

## 4. 学每一章时要抓住的问题

- 这一章解决什么任务：分类、回归、聚类、决策，还是策略学习？
- 模型输入是什么，输出是什么？
- 模型的核心假设是什么？
- 学习目标或损失函数是什么？
- 参数如何学习，超参数如何选择？
- 过拟合风险在哪里，如何控制？
- 对特征尺度、数据量、噪声、类别不平衡是否敏感？
- 与前后章节的关系是什么？

## 5. 怎么消化这些知识

不要把每章都当成“全部背下来”。每章按三层消化：

```text
第一层：能说清楚直觉
第二层：能写出核心公式或流程
第三层：能用代码跑一个最小例子
```

当前最适合的学习方法：

1. 每章先读“学习法小结”，只抓最小掌握目标。
2. 看正文时优先看例子和流程，公式先知道在解决什么问题。
3. 学完后用自测问题闭卷回答，答不出来再回去翻正文。
4. 每章最多先掌握 3 到 5 个关键概念，不要一次吞完整章。
5. 每学完 2 到 3 章，用一个小任务串起来，例如分类任务从数据划分、训练模型到指标评估。

建议优先级：

| 优先级 | 内容 | 要求 |
| --- | --- | --- |
| 必须先会 | 第 1、2、3、4、6、8、10 章 | 能解释直觉、核心流程和适用场景 |
| 第二轮再深入 | 第 5、7、9 章 | 先理解主线，再补公式和推导 |
| 做项目时补 | 数据处理、优化、解释、论文实验 | 遇到真实任务再细化 |

如果只是为了先建立机器学习体系，不需要一开始就完整推导 SVM 对偶问题、BP 反向传播细节、Bellman 方程推导。先会用、会解释、会判断适用场景，再回头补推导。

## 6. 实践项目基本流程

```text
明确问题
-> 收集数据
-> 数据清洗
-> 特征工程
-> 划分训练集/验证集/测试集
-> 建立简单基线模型
-> 按任务选择候选模型
-> 在验证集上调参
-> 在测试集上做最终评估
-> 做错误分析和模型解释
-> 部署与监控
```

## 7. 学习建议

- 按 PDF 顺序学习时，第 1、2 章先建立整体框架，第 3 到第 8 章是传统机器学习主干，第 9 章单独进入强化学习，第 10 章进入无监督学习。
- 写代码时可以优先使用 Scikit-learn 复现实验；神经网络和深度强化学习再转 PyTorch。
- 不要只背算法名。至少要能说清楚：目标函数、训练方法、关键超参数、优缺点、适用场景。
- 做论文或项目时，优先把第 2 章的评估方法、第 3/4/6/8 章的基线模型、第 15/17 章的解释和实验设计串起来。
