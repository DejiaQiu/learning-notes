# 概率统计基础

## 1. 为什么机器学习需要概率统计

机器学习中的很多概念都来自概率统计：

- 分类模型输出概率。
- 损失函数常来自极大似然估计。
- 朴素贝叶斯依赖条件概率。
- 模型评估需要均值、方差、置信区间。
- 论文实验需要显著性分析和误差分析。

如果要写研究生论文，至少要能解释实验结果是否可靠，而不是只给一个单次跑出来的指标。

## 2. 随机变量

随机变量是随机试验结果的数值表示。

类型：

- 离散随机变量：取值有限或可数，例如类别标签。
- 连续随机变量：取值连续，例如温度、速度、价格。

机器学习中：

- 输入特征可以看作随机变量。
- 标签也可以看作随机变量。
- 模型学习的是输入和输出之间的统计关系。

## 3. 概率

概率表示事件发生的可能性。

基本性质：

```text
0 <= P(A) <= 1
P(全集) = 1
P(A^c) = 1 - P(A)
```

如果 A 和 B 互斥：

```text
P(A or B) = P(A) + P(B)
```

## 4. 条件概率

条件概率表示在事件 B 已经发生的条件下，事件 A 发生的概率。

```text
P(A|B) = P(A and B) / P(B)
```

机器学习例子：

```text
P(故障|振动异常)
P(垃圾邮件|出现某些关键词)
P(疾病|检测结果阳性)
```

## 5. 贝叶斯公式

贝叶斯公式：

```text
P(A|B) = P(B|A) * P(A) / P(B)
```

含义：

- P(A)：先验概率。
- P(B|A)：似然。
- P(A|B)：后验概率。
- P(B)：证据。

朴素贝叶斯、贝叶斯推断、概率图模型都以贝叶斯思想为基础。

## 6. 独立性

如果 A 和 B 独立：

```text
P(A and B) = P(A) * P(B)
P(A|B) = P(A)
```

注意：

- 独立不等于互斥。
- 机器学习中的特征通常并不完全独立。
- 朴素贝叶斯假设特征条件独立，这是一个强假设。

## 7. 常见分布

### 7.1 伯努利分布

只有两个结果，例如成功/失败、正类/负类。

适合二分类标签建模。

### 7.2 二项分布

n 次独立伯努利试验中成功次数的分布。

例子：

- 100 个样本中预测正确的个数。

### 7.3 多项分布

二项分布的多类别扩展。

文本分类中的词频建模常会用到。

### 7.4 正态分布

也叫高斯分布。

特点：

- 钟形曲线。
- 均值决定中心位置。
- 方差决定分布宽度。

很多统计方法都依赖正态分布假设。

### 7.5 泊松分布

用于描述单位时间或单位空间内事件发生次数。

例子：

- 每小时请求数。
- 每天故障次数。

## 8. 期望与方差

### 8.1 期望

期望表示随机变量的平均水平。

```text
E(X)
```

### 8.2 方差

方差表示随机变量围绕均值的波动程度。

```text
Var(X) = E[(X - E(X))^2]
```

### 8.3 标准差

标准差是方差的平方根，量纲和原变量一致。

## 9. 协方差与相关系数

协方差衡量两个变量共同变化的方向。

相关系数是标准化后的协方差，范围为 -1 到 1。

```text
1：完全正相关
0：无线性相关
-1：完全负相关
```

注意：

- 相关不等于因果。
- 相关系数只能衡量线性关系。

## 10. 极大似然估计

极大似然估计（MLE）用于选择最可能生成观测数据的参数。

思想：

```text
给定数据，寻找让这些数据出现概率最大的参数
```

很多模型训练都可以从极大似然角度解释：

- 线性回归 + 高斯噪声 -> MSE。
- 逻辑回归 + 伯努利分布 -> 交叉熵。
- 多分类模型 + 多项分布 -> Softmax 交叉熵。

## 11. 最大后验估计

最大后验估计（MAP）在 MLE 基础上加入先验。

```text
后验 ∝ 似然 * 先验
```

正则化可以从 MAP 角度理解：

- L2 正则对应高斯先验。
- L1 正则对应拉普拉斯先验。

## 12. 抽样与估计

论文实验中，我们通常只能拿到有限样本。

需要关注：

- 样本是否代表真实总体。
- 是否存在采样偏差。
- 训练集、验证集、测试集是否分布一致。
- 实验指标是否稳定。

## 13. 置信区间

置信区间用于表示估计结果的不确定性。

例如：

```text
Accuracy = 91.2% ± 0.8%
```

这比只报告一个单点结果更可靠。

论文中如果多次重复实验，可以报告：

```text
mean ± std
```

## 14. 假设检验

假设检验用于判断两个方法的差异是否可能只是随机波动。

基本概念：

- 原假设 H0：两个方法没有显著差异。
- 备择假设 H1：两个方法存在显著差异。
- p-value：观察到当前结果或更极端结果的概率。

常见判断：

```text
p < 0.05：通常认为差异显著
```

注意：

- p-value 不是效果大小。
- 显著不等于有实际价值。
- 数据量很大时，小差异也可能显著。

## 15. 偏差与方差

模型误差可以从偏差和方差角度理解。

### 15.1 偏差

偏差表示模型假设和真实规律之间的差距。

高偏差常导致欠拟合。

### 15.2 方差

方差表示模型对训练数据变化的敏感程度。

高方差常导致过拟合。

### 15.3 偏差-方差权衡

模型太简单：

- 偏差高。
- 方差低。
- 容易欠拟合。

模型太复杂：

- 偏差低。
- 方差高。
- 容易过拟合。

## 16. 论文中常用统计表达

实验结果建议报告：

- 多次运行的均值。
- 标准差。
- 最优结果。
- 对比方法。
- 是否使用相同数据划分。
- 是否使用相同训练轮数和超参数搜索范围。

常见写法：

```text
所有实验重复运行 5 次，报告平均值和标准差。
```

## 17. 记忆重点

- 条件概率是很多机器学习模型的基础。
- 贝叶斯公式连接先验、似然和后验。
- MLE 关注让数据出现概率最大的参数。
- MAP 在 MLE 上加入先验，和正则化有关。
- 论文实验不要只报告一次结果，最好报告 mean ± std。
- 相关不等于因果。
- 偏差高容易欠拟合，方差高容易过拟合。
