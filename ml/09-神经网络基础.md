# 神经网络基础

## 1. 神经网络是什么

神经网络是一类由多层神经元组成的模型，通过多层非线性变换学习复杂函数。

基本结构：

```text
输入层 -> 隐藏层 -> 输出层
```

如果隐藏层很多，就称为深度神经网络。

## 2. 神经元

一个神经元通常做两件事：

1. 线性变换。
2. 非线性激活。

形式：

```text
z = w*x + b
a = activation(z)
```

如果没有激活函数，多层线性变换仍然等价于一层线性变换。

## 3. 常见激活函数

### 3.1 Sigmoid

输出范围是 0 到 1。

缺点：

- 容易梯度消失。
- 输出不是零中心。

常用于二分类输出层。

### 3.2 Tanh

输出范围是 -1 到 1。

相比 Sigmoid，输出是零中心。

缺点：

- 仍然可能梯度消失。

### 3.3 ReLU

```text
ReLU(x) = max(0, x)
```

优点：

- 计算简单。
- 缓解梯度消失。
- 深度学习中非常常用。

缺点：

- 可能出现 dead ReLU，即神经元长期输出 0。

### 3.4 Leaky ReLU

给负数区域保留一个很小斜率，缓解 dead ReLU。

### 3.5 Softmax

用于多分类输出层，把多个类别分数转成概率。

```text
p_i = exp(z_i) / sum(exp(z_j))
```

## 4. 前向传播

前向传播是输入数据经过网络，得到预测结果的过程。

```text
输入 X -> 第 1 层 -> 第 2 层 -> ... -> 输出 y_pred
```

## 5. 损失函数

常见选择：

- 回归：MSE、MAE。
- 二分类：Binary Cross Entropy。
- 多分类：Cross Entropy。

损失函数衡量预测结果和真实标签之间的差距。

## 6. 反向传播

反向传播用于计算每个参数对损失的梯度。

核心思想：

```text
利用链式法则，从输出层往前逐层计算梯度
```

训练过程：

1. 前向传播得到预测。
2. 计算损失。
3. 反向传播计算梯度。
4. 优化器更新参数。
5. 重复以上步骤。

## 7. 梯度下降

参数更新形式：

```text
w = w - learning_rate * gradient
```

学习率太大：

- 损失震荡。
- 甚至不收敛。

学习率太小：

- 收敛很慢。
- 容易卡在局部区域。

## 8. 常见优化器

### 8.1 SGD

随机梯度下降，每次用一个 batch 的数据更新参数。

优点：

- 简单。
- 泛化能力常常不错。

缺点：

- 收敛可能慢。

### 8.2 Momentum

加入动量，减少震荡，加速收敛。

### 8.3 Adam

结合一阶矩和二阶矩估计，自适应调整学习率。

优点：

- 默认效果通常较好。
- 调参成本较低。

### 8.4 AdamW

AdamW 改进了权重衰减处理方式，在深度学习中很常用。

## 9. Batch

训练时通常不会一次使用全部数据，而是分 batch 训练。

概念：

- batch size：每次训练使用的样本数。
- epoch：完整遍历训练集一次。
- iteration：一次参数更新。

关系：

```text
iterations_per_epoch = 训练样本数 / batch_size
```

## 10. 权重初始化

初始化不好会导致训练困难。

常见方法：

- Xavier 初始化：适合 Sigmoid、Tanh。
- He 初始化：适合 ReLU 系列。

## 11. 梯度消失和梯度爆炸

### 11.1 梯度消失

反向传播时梯度越来越小，前面层几乎学不动。

常见原因：

- 网络太深。
- 使用 Sigmoid/Tanh。
- 初始化不合适。

解决方法：

- 使用 ReLU。
- 使用 BatchNorm。
- 使用残差连接。
- 合理初始化。

### 11.2 梯度爆炸

梯度过大，导致参数更新不稳定。

解决方法：

- 梯度裁剪。
- 降低学习率。
- 合理初始化。
- 使用归一化层。

## 12. MLP

MLP 是多层感知机，适合普通向量数据。

结构：

```text
输入 -> 全连接层 -> 激活 -> 全连接层 -> 激活 -> 输出
```

缺点：

- 对图像这类具有空间结构的数据不够高效。
- 参数量可能很大。

图像任务中通常使用 CNN。

## 13. 记忆重点

- 神经网络通过多层非线性变换学习复杂函数。
- 激活函数提供非线性能力。
- 反向传播使用链式法则计算梯度。
- 学习率是非常关键的超参数。
- ReLU 是隐藏层常用激活函数。
- Softmax 常用于多分类输出层。
- Adam 和 AdamW 是常用优化器。
