# 数据处理与特征工程

## 1. 为什么数据处理重要

机器学习模型的效果很大程度取决于数据质量。错误数据、缺失数据、标签噪声和数据泄漏会直接影响模型效果。

一个实用判断：

```text
好数据 + 普通模型 > 差数据 + 复杂模型
```

## 2. 数据清洗

### 2.1 缺失值

常见处理方式：

- 删除缺失严重的字段。
- 删除缺失严重的样本。
- 用均值、中位数、众数填充。
- 用固定值填充，如 unknown、0。
- 用模型预测缺失值。
- 增加“是否缺失”的指示特征。

选择方法时要看业务含义。例如收入缺失可能不是随机缺失，而是用户不愿意填写，这本身可能有信息。

### 2.2 重复值

重复数据会让模型对某些样本过度学习。

处理方式：

- 完全重复的样本通常可以去重。
- 同一个实体的多条记录要看是否代表不同时间或不同状态。

### 2.3 异常值

异常值可能是真实极端样本，也可能是采集错误。

常见识别方式：

- 箱线图 IQR。
- Z-score。
- 业务规则。
- Isolation Forest。
- 聚类距离。

处理方式：

- 删除错误数据。
- 截断到合理范围。
- 单独作为异常类别。
- 保留并使用鲁棒模型。

### 2.4 标签噪声

标签错误比特征错误更危险，因为模型会学习错误目标。

处理方法：

- 抽样人工检查。
- 找训练损失长期很大的样本。
- 多人标注投票。
- 对可疑标签降权。

## 3. 数值特征处理

### 3.1 标准化

把特征变成均值为 0、标准差为 1 的分布。

```text
x' = (x - mean) / std
```

适合：

- 线性模型
- KNN
- SVM
- 神经网络
- PCA

### 3.2 归一化

把特征缩放到固定范围，如 0 到 1。

```text
x' = (x - min) / (max - min)
```

适合：

- 距离度量敏感模型。
- 神经网络输入。

### 3.3 鲁棒缩放

使用中位数和四分位距，适合异常值较多的数据。

```text
x' = (x - median) / IQR
```

## 4. 类别特征处理

### 4.1 One-Hot Encoding

把类别变成多个 0/1 特征。

优点：

- 简单。
- 不引入类别顺序。

缺点：

- 高基数类别会导致维度很高。

### 4.2 Label Encoding

把类别映射为整数。

注意：

- 对树模型通常可用。
- 对线性模型可能引入错误的大小关系。

### 4.3 Target Encoding

用类别对应的目标均值表示类别。

注意：

- 容易数据泄漏。
- 必须在交叉验证或训练折内计算。

## 5. 时间特征

时间字段通常不能直接丢给模型，要拆成更有意义的特征。

常见特征：

- 年、月、日、小时、分钟。
- 星期几。
- 是否周末。
- 是否节假日。
- 距离上次行为的时间。
- 滚动窗口统计量。

时间序列相关特征要注意不能使用未来信息。

## 6. 文本特征

传统方法：

- 分词
- Bag of Words
- TF-IDF
- n-gram

深度学习方法：

- Word2Vec
- GloVe
- FastText
- BERT/Transformer Embedding

## 7. 图像特征

传统图像特征：

- HOG
- SIFT
- 颜色直方图

深度学习中，通常使用 CNN 自动提取图像特征。

常见预处理：

- resize
- normalize
- random crop
- random flip
- color jitter

## 8. 特征选择

特征选择用于删除无效、冗余或有害特征。

方法：

- 方差过滤：删除几乎不变化的特征。
- 相关性过滤：删除高度相关的冗余特征。
- 卡方检验。
- 互信息。
- L1 正则。
- 树模型特征重要性。
- 递归特征消除 RFE。

## 9. 特征构造

常见方式：

- 比值特征：点击率 = 点击数 / 曝光数。
- 差值特征：当前值 - 历史均值。
- 统计特征：均值、最大值、最小值、标准差。
- 分桶特征：年龄段、价格区间。
- 交叉特征：城市 + 品类。

好的特征构造通常来自业务理解。

## 10. 类别不平衡

类别不平衡指不同类别样本数量差异很大。

常见方法：

- 欠采样多数类。
- 过采样少数类。
- SMOTE。
- 调整类别权重。
- 调整分类阈值。
- 使用 F1、Recall、Precision、AUC 等指标。

不要只看 Accuracy。例如 99% 样本是正常类，模型全部预测正常也有 99% 准确率，但没有实际价值。

## 11. Pipeline

推荐把预处理和模型放进 Pipeline：

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

model = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("clf", LogisticRegression(max_iter=1000)),
    ]
)
```

好处：

- 避免数据泄漏。
- 方便交叉验证。
- 方便部署。
- 保证训练和预测使用同样的处理流程。
