# KNN 与朴素贝叶斯

## 学习法小结

这一章重点放在朴素贝叶斯，对应 PDF 第 7 章；KNN 作为补充 baseline 学即可。

学习顺序：

1. 先用 KNN 建立“基于相似度分类”的直觉。
2. 再复习贝叶斯公式，理解后验概率最大化。
3. 然后看朴素贝叶斯的条件独立假设。
4. 最后看拉普拉斯平滑如何避免概率为 0。

最小掌握目标：

- 能解释 KNN 为什么对特征缩放敏感。
- 能写出朴素贝叶斯分类时比较的核心概率。
- 能说明拉普拉斯平滑解决什么问题。

自测问题：

- K 值太小和太大分别有什么风险？
- 为什么朴素贝叶斯常用于文本分类？
- 一个词在训练集中从未出现时，为什么会导致概率计算问题？

## 1. 为什么学习这两个模型

KNN 和朴素贝叶斯都是经典机器学习模型。

它们的价值：

- 思想简单，适合理解分类问题。
- 常作为 baseline。
- 在部分任务上仍然有效。
- 能帮助理解距离度量和概率建模。

例子：
如果你刚开始学分类，KNN 能帮你理解“像谁就分到谁那类”，朴素贝叶斯能帮你理解“根据概率来选最可能的类别”。这两个模型都很适合拿来建立直觉。

## 2. KNN

KNN 全称 K-Nearest Neighbors，K 近邻算法。

核心思想：

```text
一个样本的类别由离它最近的 K 个训练样本决定
```

例子：
要判断一个新水果是不是苹果，可以看它在“重量、甜度、颜色”空间里更接近训练集里的苹果还是橙子。最近邻居大多是苹果，那它大概率也被分成苹果。

## 3. KNN 分类流程

1. 计算测试样本和所有训练样本的距离。
2. 找到距离最近的 K 个样本。
3. 统计这 K 个样本的类别。
4. 投票得到预测类别。

回归任务中，通常取 K 个邻居标签值的平均。

例子：
如果最近的 5 个邻居里有 4 个是“正常设备”、1 个是“异常设备”，那分类结果通常就是正常；如果是房价回归，就对这 5 套相似房源的价格求平均。

## 4. 距离度量

### 4.1 欧氏距离

最常用距离。

$$
d(x, y) = \sqrt{\sum_i (x_i - y_i)^2}
$$

### 4.2 曼哈顿距离

$$
d(x, y) = \sum_i |x_i - y_i|
$$

### 4.3 余弦相似度

常用于文本向量。

关注方向相似度，而不是绝对大小。

例子：
两篇新闻长度可能差很多，但只要关键词分布方向相似，余弦相似度就会比较高，所以它特别适合文本表示。

## 5. K 的影响

K 太小：

- 模型复杂。
- 容易受噪声影响。
- 可能过拟合。

K 太大：

- 决策边界更平滑。
- 可能欠拟合。
- 少数类容易被多数类淹没。

常用方法：

- 交叉验证选择 K。
- K 通常取奇数，减少投票平局。

例子：
如果 $K=1$，一个噪声点就可能把新样本带偏；如果 $K=51$，少数类样本很容易被多数类淹没。$K$ 本质上是在调模型到底看“很局部”还是“更大范围”的邻居。

## 6. KNN 的优点

- 思想简单。
- 不需要显式训练过程。
- 可以处理非线性边界。
- 适合作为小数据 baseline。

例子：
当你只有几百条样本，想先快速知道“这个问题是不是有可分性”时，KNN 往往比一上来调复杂模型更直接。

## 7. KNN 的缺点

- 预测速度慢。
- 存储训练数据成本高。
- 对特征尺度敏感。
- 高维数据中距离度量效果变差。
- 对类别不平衡敏感。

例子：
如果特征维度有几千维，很多样本之间的距离都会变得差不多，这时“最近邻”本身就不那么可信了，这就是高维空间里的距离退化问题。

## 8. KNN 使用注意

必须考虑特征缩放。

例如年龄范围是 0 到 100，收入范围是 0 到 100000，如果不标准化，收入会主导距离计算。

推荐使用 Pipeline：

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

model = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("knn", KNeighborsClassifier(n_neighbors=5)),
    ]
)
```

例子：
如果年龄范围是 20 到 60，而收入范围是 3000 到 300000，不标准化时 KNN 几乎只会按收入找邻居，年龄信息基本被淹没。

## 9. 朴素贝叶斯

朴素贝叶斯是一类基于贝叶斯公式的分类模型。

贝叶斯公式：

$$
P(y \mid x) = \frac{P(x \mid y)P(y)}{P(x)}
$$

分类时选择后验概率最大的类别：

$$
\hat{y} = \arg\max_y P(y \mid x)
$$

例子：
在垃圾邮件分类里，模型会比较“这封邮件在垃圾类下出现的概率”和“在正常类下出现的概率”，哪个更大就判给哪个类别。

## 10. 朴素的含义

“朴素”指特征条件独立假设。

给定类别 y 后，假设各个特征相互独立：

$$
P(x_1, x_2, \ldots, x_n \mid y) = \prod_{i=1}^{n} P(x_i \mid y)
$$

这个假设现实中通常不完全成立，但模型依然经常有效。

例子：
在垃圾邮件里，“免费”和“优惠”这两个词其实常常一起出现，并不独立。朴素贝叶斯是假装它们独立来简化计算，虽然假设不严格，但很多时候依然好用。

## 11. 朴素贝叶斯分类公式

因为 P(x) 对所有类别相同，分类时可以忽略：

$$
\hat{y} = \arg\max_y P(y)\prod_{i=1}^{n}P(x_i \mid y)
$$

实际计算中常用 log，避免概率连乘下溢：

$$
\log P(y) + \sum_{i=1}^{n}\log P(x_i \mid y)
$$

例子：
如果一封邮件同时出现“免费”“中奖”“立即领取”这些词，而这些词在垃圾邮件里都很常见，那么垃圾类对应的对数概率和就会更大。

## 12. 常见朴素贝叶斯模型

### 12.1 GaussianNB

假设连续特征服从正态分布。

适合：

- 连续数值特征。

例子：
如果输入是用户年龄、收入、停留时长这类连续值，GaussianNB 会假设这些特征在每个类别下近似服从正态分布。

### 12.2 MultinomialNB

适合离散计数特征。

常用于：

- 文本分类。
- 词频特征。
- TF-IDF 特征。

例子：
新闻分类、垃圾邮件识别、评论情感分析这类“词出现次数很重要”的任务，经常能用 MultinomialNB 快速做出不错基线。

### 12.3 BernoulliNB

适合二值特征。

例如：

- 某个词是否出现。
- 某个事件是否发生。

例子：
如果你只关心“邮件里有没有出现退款、中奖、发票这些词”，而不关心它们出现几次，BernoulliNB 就比较合适。

## 13. 拉普拉斯平滑

如果某个词在某个类别中从未出现，概率会变成 0，导致整个类别概率为 0。

拉普拉斯平滑用于避免零概率：

$$
P = \frac{\mathrm{count} + \alpha}{\mathrm{total} + \alpha \cdot K}
$$

alpha 通常取 1。

例子：
如果训练集中“退款”这个词从没在正常邮件里出现过，不做平滑时它在正常类下的概率就是 0，只要测试邮件出现这个词，正常类整体概率就会直接被乘成 0，这会太极端。

## 14. 朴素贝叶斯优点

- 简单快速。
- 小数据上表现稳定。
- 适合高维稀疏文本特征。
- 对缺失部分特征不太敏感。
- 可解释性较好。

例子：
你需要一个几分钟内就能跑完的文本分类基线时，朴素贝叶斯往往非常划算，因为它训练快、实现也简单。

## 15. 朴素贝叶斯缺点

- 条件独立假设较强。
- 特征高度相关时效果可能下降。
- 不能很好学习复杂特征交互。
- 输出概率可能校准不好。

例子：
如果一句话里“不是很好”和“很好”同时出现，真实语义依赖上下文组合，这种复杂交互就不是朴素贝叶斯擅长的。

## 16. 文本分类示例

```python
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB

model = Pipeline(
    steps=[
        ("tfidf", TfidfVectorizer()),
        ("clf", MultinomialNB(alpha=1.0)),
    ]
)

model.fit(train_texts, train_labels)
preds = model.predict(test_texts)
```

## 17. KNN 和朴素贝叶斯对比

| 项目 | KNN | 朴素贝叶斯 |
| --- | --- | --- |
| 思想 | 看邻居 | 看概率 |
| 训练成本 | 几乎没有 | 低 |
| 预测成本 | 高 | 低 |
| 是否依赖特征缩放 | 是 | 通常不强 |
| 适合数据 | 小规模、低维 | 文本、高维稀疏 |
| 主要问题 | 高维距离失效 | 条件独立假设过强 |

例子：
做用户画像分类时，样本少、特征维度不高，可以先试 KNN；做新闻分类时，特征是稀疏词向量，通常朴素贝叶斯更自然。

## 18. 论文中如何使用

KNN 和朴素贝叶斯通常适合作为 baseline。

论文写法可以是：

```text
为验证所提方法的有效性，本文选取 KNN、朴素贝叶斯、逻辑回归、随机森林等传统方法作为对比基线。
```

注意：

- baseline 要使用合理参数。
- 不能故意让 baseline 很弱。
- 所有方法应使用相同训练集和测试集。

例子：
如果你论文主打一个新文本分类模型，把 `MultinomialNB` 和 `LogisticRegression` 作为传统 baseline 往往是合理的；但如果你故意不给 baseline 做基本调参，比较就没有说服力。

## 19. 记忆重点

- KNN 基于距离，必须重视特征缩放。
- K 越小模型越复杂，K 越大模型越平滑。
- 朴素贝叶斯基于贝叶斯公式。
- 朴素贝叶斯的核心假设是特征条件独立。
- MultinomialNB 常用于文本分类。
- 拉普拉斯平滑用于避免零概率。
