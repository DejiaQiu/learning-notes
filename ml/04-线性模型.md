# 线性模型

## 1. 线性模型的核心思想

线性模型假设目标值可以由特征的线性组合表示。

```text
y = w1*x1 + w2*x2 + ... + wn*xn + b
```

其中：

- x 是输入特征。
- w 是权重。
- b 是偏置。
- y 是预测结果。

线性模型简单、速度快、可解释性强，常作为机器学习基线模型。

## 2. 线性回归

线性回归用于回归任务，输出连续数值。

### 2.1 目标

寻找一组参数 w 和 b，使预测值尽量接近真实值。

常用损失函数：

```text
MSE = mean((y - y_pred)^2)
```

### 2.2 优点

- 简单。
- 训练速度快。
- 可解释。
- 适合做基线模型。

### 2.3 缺点

- 难以拟合复杂非线性关系。
- 对异常值敏感。
- 对多重共线性敏感。

## 3. 多项式回归

多项式回归通过增加特征的高次项来拟合非线性关系。

例子：

```text
y = w1*x + w2*x^2 + w3*x^3 + b
```

注意：

- 阶数太低容易欠拟合。
- 阶数太高容易过拟合。

## 4. 逻辑回归

逻辑回归用于分类任务，尤其是二分类。

虽然名字里有“回归”，但它是分类模型。

### 4.1 Sigmoid 函数

逻辑回归把线性输出通过 Sigmoid 函数转换成概率。

```text
p = 1 / (1 + exp(-z))
z = w*x + b
```

如果 p 大于阈值，预测为正类；否则预测为负类。

### 4.2 损失函数

二分类常用交叉熵损失：

```text
Loss = -[y*log(p) + (1-y)*log(1-p)]
```

### 4.3 优点

- 训练快。
- 输出概率。
- 可解释性较好。
- 适合高维稀疏特征。

### 4.4 缺点

- 线性决策边界，表达能力有限。
- 需要一定特征工程。
- 对异常值和特征尺度较敏感。

## 5. Softmax 回归

Softmax 回归是逻辑回归的多分类扩展。

Softmax 把多个类别的得分转换成概率分布：

```text
p_i = exp(z_i) / sum(exp(z_j))
```

所有类别概率之和为 1。

## 6. 正则化

正则化用于限制模型复杂度，减少过拟合。

### 6.1 L1 正则

L1 正则会让部分权重变成 0，有特征选择效果。

```text
Loss = 原始损失 + lambda * sum(|w|)
```

### 6.2 L2 正则

L2 正则会让权重整体变小，使模型更平滑。

```text
Loss = 原始损失 + lambda * sum(w^2)
```

### 6.3 Elastic Net

Elastic Net 同时使用 L1 和 L2。

适合：

- 特征很多。
- 特征之间存在相关性。

## 7. 线性模型对特征的要求

通常需要：

- 处理缺失值。
- 标准化数值特征。
- 对类别特征编码。
- 处理异常值。
- 删除强数据泄漏特征。

线性模型对特征缩放敏感，尤其是使用正则化时。

## 8. 多重共线性

多重共线性指多个特征之间高度相关。

影响：

- 权重不稳定。
- 可解释性下降。
- 模型对小扰动敏感。

处理方式：

- 删除冗余特征。
- 使用 L2 正则。
- 使用 PCA。

## 9. 适用场景

适合：

- 数据量不大。
- 特征和目标关系接近线性。
- 需要可解释性。
- 需要快速训练和预测。
- 文本分类中的高维稀疏特征。

不适合：

- 强非线性关系。
- 复杂图像和语音任务。
- 特征交互非常复杂但没有做特征工程的场景。
