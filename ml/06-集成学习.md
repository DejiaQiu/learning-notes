# 集成学习

## 学习法小结

这一章只需要先分清两条主线：Bagging 降方差，Boosting 降偏差并逐步纠错。

学习顺序：

1. 先理解为什么多个弱模型组合可能比单模型稳定。
2. 再看 Bagging：有放回采样、并行训练、投票或平均。
3. 再看随机森林：在 Bagging 上增加特征随机性。
4. 最后看 Boosting/AdaBoost：后一轮更关注上一轮分错的样本。

最小掌握目标：

- 能解释 Bootstrap 和 OOB 是什么。
- 能说出随机森林比单棵决策树强在哪里。
- 能解释 AdaBoost 中样本权重为什么会变化。

自测问题：

- Bagging 和 Boosting 的训练方式是并行还是串行？
- 随机森林主要缓解偏差还是方差？
- 为什么 Boosting 容易受噪声样本影响？

## 1. 什么是集成学习

集成学习通过组合多个弱模型，得到一个更强的模型。

核心思想：

$$
\text{多个模型的组合效果} > \text{单个模型效果}
$$

集成学习常用于提升稳定性、准确率和泛化能力。

## 2. 主要类型

集成学习常见方法：

- Bagging
- Boosting
- Stacking

## 3. Bagging

Bagging 全称 Bootstrap Aggregating。

流程：

1. 从训练集中有放回采样，得到多个子训练集。
2. 每个子训练集训练一个模型。
3. 分类任务投票，回归任务取平均。

特点：

- 各模型并行训练。
- 主要降低方差。
- 适合不稳定模型，如决策树。

## 4. 随机森林

随机森林是 Bagging 的典型代表。

它在 Bagging 的基础上增加了特征随机性：

- 样本随机。
- 特征随机。

每棵树训练时，只在部分特征中选择最优划分。

### 4.1 优点

- 泛化能力比单棵树强。
- 不容易过拟合。
- 能处理非线性关系。
- 对特征缩放不敏感。
- 可以输出特征重要性。

### 4.2 缺点

- 可解释性弱于单棵树。
- 模型体积较大。
- 预测速度比单棵树慢。

### 4.3 重要参数

- n_estimators：树的数量。
- max_depth：树最大深度。
- max_features：每次划分考虑的特征数量。
- min_samples_leaf：叶子节点最少样本数。
- class_weight：类别权重。

## 5. Boosting

Boosting 是串行训练多个弱模型，后一个模型重点修正前面模型的错误。

特点：

- 模型串行训练。
- 主要降低偏差。
- 容易获得高精度。
- 参数不当时容易过拟合。

## 6. AdaBoost

AdaBoost 的核心思想：

- 先训练一个弱分类器。
- 提高被错误分类样本的权重。
- 再训练下一个弱分类器。
- 最后对多个分类器加权投票。

适合：

- 简单弱学习器。
- 中小规模数据。

缺点：

- 对异常值和噪声敏感。

## 7. GBDT

GBDT 全称 Gradient Boosting Decision Tree。

核心思想：

$$
\text{每一棵新树都拟合前面模型的残差或负梯度}
$$

GBDT 是很多强大树模型的基础。

### 7.1 优点

- 表格数据上效果强。
- 能处理非线性和特征交互。
- 对特征缩放不敏感。

### 7.2 缺点

- 串行训练，速度可能较慢。
- 参数较多。
- 调参不当容易过拟合。

## 8. XGBoost

XGBoost 是工程优化和正则化增强版的 GBDT。

特点：

- 加入二阶梯度信息。
- 加入正则化项。
- 支持列采样。
- 支持缺失值处理。
- 支持并行优化。

常见参数：

- n_estimators
- learning_rate
- max_depth
- subsample
- colsample_bytree
- reg_alpha
- reg_lambda

## 9. LightGBM

LightGBM 是微软提出的高效 GBDT 实现。

特点：

- 基于直方图算法。
- leaf-wise 生长策略。
- 训练速度快。
- 内存占用低。
- 适合大规模表格数据。

注意：

- leaf-wise 容易长出较深的树。
- 需要控制 num_leaves、max_depth、min_data_in_leaf。

## 10. CatBoost

CatBoost 对类别特征处理较强。

特点：

- 原生支持类别特征。
- 使用 Ordered Target Encoding 缓解数据泄漏。
- 对默认参数较友好。

适合：

- 类别特征较多的表格任务。

## 11. Stacking

Stacking 用多个基础模型的输出作为新特征，再训练一个元模型。

流程：

1. 训练多个一级模型。
2. 用交叉验证得到一级模型对训练集的预测。
3. 把这些预测作为新特征。
4. 训练二级模型。

注意：

- 必须用交叉验证方式生成训练预测，避免数据泄漏。
- 元模型通常使用简单模型，如逻辑回归、线性回归。

## 12. Bagging 和 Boosting 对比

| 项目 | Bagging | Boosting |
| --- | --- | --- |
| 训练方式 | 并行 | 串行 |
| 样本使用 | 有放回采样 | 关注前面错的样本 |
| 主要作用 | 降低方差 | 降低偏差 |
| 代表模型 | 随机森林 | AdaBoost、GBDT、XGBoost |
| 对噪声敏感度 | 较低 | 较高 |

## 13. 示例

```python
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

rf = RandomForestClassifier(
    n_estimators=200,
    max_depth=None,
    min_samples_leaf=2,
    random_state=42,
)

gbdt = GradientBoostingClassifier(
    n_estimators=200,
    learning_rate=0.05,
    max_depth=3,
    random_state=42,
)
```

## 14. 记忆重点

- Bagging 主要降低方差。
- Boosting 主要降低偏差。
- 随机森林 = Bagging + 决策树 + 特征随机。
- GBDT 每棵树拟合前面模型的残差或负梯度。
- XGBoost 加强了正则化和工程优化。
- LightGBM 速度快，适合大规模表格数据。
- CatBoost 适合类别特征较多的数据。
