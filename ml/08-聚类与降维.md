# 聚类与降维

## 1. 无监督学习

无监督学习的数据没有标签，模型需要从数据中发现结构。

常见任务：

- 聚类。
- 降维。
- 异常检测。
- 可视化。

## 2. 聚类

聚类是把相似样本分到同一组。

聚类结果通常用于：

- 用户分群。
- 商品分组。
- 图像分割。
- 异常检测。
- 数据探索。

## 3. K-Means

K-Means 是最经典的聚类算法之一。

### 3.1 核心思想

给定簇数 K，将样本划分成 K 个簇，使每个样本到所属簇中心的距离尽可能小。

流程：

1. 随机初始化 K 个中心点。
2. 将每个样本分配给最近的中心点。
3. 重新计算每个簇的中心点。
4. 重复 2 和 3，直到中心点基本不变。

### 3.2 优点

- 简单。
- 速度快。
- 适合大规模数据。

### 3.3 缺点

- 需要提前指定 K。
- 对初始中心敏感。
- 对异常值敏感。
- 假设簇是近似球形。
- 对特征缩放敏感。

### 3.4 如何选择 K

常见方法：

- 肘部法。
- 轮廓系数。
- 结合业务解释性。

## 4. DBSCAN

DBSCAN 是基于密度的聚类算法。

核心参数：

- eps：邻域半径。
- min_samples：形成核心点所需的最少样本数。

样本类型：

- 核心点：eps 范围内样本数足够多。
- 边界点：不是核心点，但在某个核心点邻域内。
- 噪声点：不属于任何簇。

优点：

- 不需要提前指定簇数。
- 可以发现任意形状簇。
- 可以识别噪声点。

缺点：

- 对 eps 敏感。
- 高维数据中距离度量效果变差。
- 不适合密度差异很大的数据。

## 5. 层次聚类

层次聚类会构建样本之间的层次结构。

两种方式：

- 凝聚型：一开始每个样本是一个簇，然后逐步合并。
- 分裂型：一开始所有样本一个簇，然后逐步拆分。

优点：

- 不一定需要提前指定簇数。
- 可以用树状图观察层次关系。

缺点：

- 大数据上计算成本高。
- 合并或拆分一旦完成，通常不会回退。

## 6. 聚类评估

没有标签时：

- Silhouette Score：轮廓系数，越大越好。
- Calinski-Harabasz Index：越大越好。
- Davies-Bouldin Index：越小越好。

有标签时：

- ARI
- NMI
- Purity

聚类评估不能只看指标，还要看业务解释性。

## 7. 降维

降维是把高维数据映射到低维空间。

目的：

- 可视化。
- 去噪。
- 减少计算量。
- 缓解维度灾难。
- 提取主要信息。

## 8. PCA

PCA 是最经典的线性降维方法。

核心思想：

```text
找到一组新的坐标轴，使数据在前几个坐标轴上的方差最大
```

第一主成分保留最大方差，第二主成分在与第一主成分正交的方向上保留最大方差。

### 8.1 PCA 步骤

1. 数据标准化。
2. 计算协方差矩阵。
3. 求特征值和特征向量。
4. 按特征值从大到小排序。
5. 选择前 k 个主成分。
6. 将数据投影到低维空间。

### 8.2 explained_variance_ratio

表示每个主成分解释的方差比例。

例如：

```text
[0.6, 0.25, 0.1]
```

说明前三个主成分分别解释 60%、25%、10% 的方差。

### 8.3 PCA 优缺点

优点：

- 简单高效。
- 可减少冗余特征。
- 有明确数学解释。

缺点：

- 只能捕捉线性结构。
- 主成分可解释性可能较弱。
- 对特征尺度敏感。

## 9. t-SNE

t-SNE 常用于高维数据可视化。

特点：

- 能保留局部邻域结构。
- 适合降到 2 维或 3 维展示。

缺点：

- 计算成本高。
- 全局距离不一定可靠。
- 参数 perplexity 影响较大。

## 10. UMAP

UMAP 也是常用降维可视化方法。

特点：

- 通常比 t-SNE 快。
- 能较好保留局部和部分全局结构。
- 常用于单细胞、生物信息、图像嵌入可视化。

## 11. 示例

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.decomposition import PCA

kmeans = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("cluster", KMeans(n_clusters=3, random_state=42, n_init="auto")),
    ]
)

pca = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("pca", PCA(n_components=2)),
    ]
)
```

## 12. 记忆重点

- 聚类是无监督学习，没有标签时评估较困难。
- K-Means 需要指定 K，对尺度和异常值敏感。
- DBSCAN 不需要指定簇数，可以识别噪声。
- PCA 是线性降维，目标是保留最大方差。
- t-SNE 和 UMAP 常用于可视化，不一定适合直接作为通用建模特征。
