# 模型评估与调参

## 1. 为什么要评估

训练集表现好不代表模型真正好。机器学习关注的是模型对未知数据的泛化能力。

评估要回答：

- 模型在新数据上效果如何？
- 模型是否过拟合？
- 当前模型是否比基线模型更好？
- 不同模型之间谁更适合当前任务？
- 错误预测的业务代价是什么？

## 2. 分类任务指标

### 2.1 混淆矩阵

```text
TP：预测为正，实际为正
TN：预测为负，实际为负
FP：预测为正，实际为负
FN：预测为负，实际为正
```

### 2.2 Accuracy

准确率表示预测正确的样本占总样本的比例。

```text
Accuracy = (TP + TN) / (TP + TN + FP + FN)
```

适合类别比较均衡的任务。

### 2.3 Precision

精确率表示预测为正的样本中有多少是真的正样本。

```text
Precision = TP / (TP + FP)
```

关注误报成本高的场景，例如垃圾邮件误杀正常邮件。

### 2.4 Recall

召回率表示真实正样本中有多少被模型找出来。

```text
Recall = TP / (TP + FN)
```

关注漏报成本高的场景，例如疾病筛查、故障检测。

### 2.5 F1-score

F1 是 Precision 和 Recall 的调和平均。

```text
F1 = 2 * Precision * Recall / (Precision + Recall)
```

适合类别不平衡，且 Precision 和 Recall 都重要的场景。

### 2.6 ROC-AUC

ROC-AUC 衡量模型区分正负样本的能力。

特点：

- 对分类阈值不敏感。
- 常用于二分类模型比较。
- 类别极度不平衡时，也要结合 PR-AUC。

### 2.7 PR-AUC

PR-AUC 关注 Precision-Recall 曲线下的面积。

适合正样本很少的任务，例如欺诈检测、缺陷检测。

## 3. 回归任务指标

### 3.1 MAE

平均绝对误差：

```text
MAE = mean(|y - y_pred|)
```

优点：

- 直观。
- 对异常值不如 MSE 敏感。

### 3.2 MSE

均方误差：

```text
MSE = mean((y - y_pred)^2)
```

特点：

- 对大误差惩罚更重。
- 容易受异常值影响。

### 3.3 RMSE

均方根误差：

```text
RMSE = sqrt(MSE)
```

量纲和目标值一致，方便解释。

### 3.4 R2

R2 表示模型解释目标变量方差的比例。

```text
R2 = 1 - SSE / SST
```

R2 越接近 1 越好，但不能单独作为唯一判断。

## 4. 聚类任务指标

无监督学习没有真实标签时，评估较困难。

常见指标：

- 轮廓系数 Silhouette Score。
- Calinski-Harabasz Index。
- Davies-Bouldin Index。

如果有真实标签，可以使用：

- ARI
- NMI
- Purity

## 5. 交叉验证

K 折交叉验证：

```text
把数据分成 K 份
每次用 1 份做验证集，其余 K-1 份做训练集
重复 K 次
最后取平均结果
```

优点：

- 评估更稳定。
- 充分利用数据。
- 适合数据量不大的情况。

注意：

- 时间序列不能普通随机 K 折。
- 有用户/设备分组时，要用 GroupKFold。
- 类别不平衡时，可以用 StratifiedKFold。

## 6. 调参方法

### 6.1 手动调参

根据经验逐步调整，适合快速试验。

### 6.2 网格搜索

遍历所有参数组合。

优点：

- 系统全面。

缺点：

- 参数多时计算量大。

### 6.3 随机搜索

从参数空间随机采样。

优点：

- 通常比网格搜索更高效。
- 适合参数范围较大时。

### 6.4 贝叶斯优化

根据历史实验结果，选择更可能提升效果的参数。

常见工具：

- Optuna
- Hyperopt
- Ray Tune

## 7. 常见超参数

| 模型 | 重要超参数 |
| --- | --- |
| KNN | n_neighbors、distance metric |
| 决策树 | max_depth、min_samples_split、min_samples_leaf |
| 随机森林 | n_estimators、max_depth、max_features |
| GBDT/XGBoost | learning_rate、n_estimators、max_depth、subsample |
| SVM | C、kernel、gamma |
| 神经网络 | learning_rate、batch_size、层数、隐藏单元数、dropout |

## 8. 调参顺序建议

1. 先保证数据划分正确。
2. 建立简单基线。
3. 固定评估指标。
4. 调整对模型影响最大的参数。
5. 对比训练集和验证集表现。
6. 找到稳定参数后再做更细搜索。
7. 最后只在测试集上评估一次。

## 9. 错误分析

错误分析比盲目调参更重要。

要检查：

- 哪些类别错得最多？
- 错误样本是否集中在某些时间段？
- 错误样本是否来自某些用户或设备？
- 是否存在标签错误？
- 是否缺少关键特征？
- 是否有数据分布变化？

## 10. 模型选择原则

- 小数据表格任务：先试线性模型、树模型。
- 中大型表格任务：随机森林、GBDT、XGBoost、LightGBM。
- 高维稀疏文本：线性模型、朴素贝叶斯、Transformer。
- 图像任务：CNN、预训练模型。
- 强可解释要求：线性模型、决策树、可解释 GBDT。
- 低延迟要求：优先考虑简单模型或压缩后的模型。
