# 论文实验设计与写作

## 1. 为什么单独整理论文实验

研究生论文不是只写模型原理，还要证明方法有效。

论文实验需要回答：

- 你的方法比谁好？
- 为什么好？
- 好在哪里？
- 是否稳定？
- 是否可复现？
- 是否有局限？

如果实验设计不严谨，模型指标再高也很难支撑论文结论。

## 2. 研究问题

写论文前要明确研究问题。

一个好的研究问题应该具体：

```text
不够好：研究机器学习分类方法
更好：研究类别不平衡条件下设备故障识别方法
```

研究问题通常包括：

- 数据对象。
- 任务类型。
- 现有方法不足。
- 本文想解决的关键问题。

## 3. Baseline

Baseline 是对比方法。

常见 baseline：

- 简单统计方法。
- 传统机器学习方法。
- 当前主流深度学习方法。
- 公开论文中的代表方法。
- 去掉某个模块后的模型。

选择原则：

- 不能太弱。
- 要和任务相关。
- 要覆盖传统方法和先进方法。
- 参数设置要公平。

## 4. 数据集描述

论文中要清楚描述数据集：

- 数据来源。
- 样本数量。
- 类别数量。
- 特征维度。
- 训练/验证/测试划分。
- 类别分布。
- 数据预处理方式。
- 是否公开。

如果是自建数据集，要说明采集过程和标注方式。

## 5. 数据划分

常见划分：

```text
训练集 / 验证集 / 测试集
```

注意：

- 测试集不能参与调参。
- 时间序列按时间划分。
- 同一用户、设备、病人、订单的数据不要同时出现在训练集和测试集。
- 类别不平衡时使用分层抽样。

## 6. 评价指标

指标要和任务目标一致。

分类任务：

- Accuracy。
- Precision。
- Recall。
- F1-score。
- ROC-AUC。
- PR-AUC。

回归任务：

- MAE。
- MSE。
- RMSE。
- R2。

分割任务：

- IoU。
- mIoU。
- Dice。

目标检测：

- mAP。
- Precision。
- Recall。

异常检测：

- Recall。
- F1-score。
- PR-AUC。
- False Alarm Rate。

类别不平衡时，不要只报告 Accuracy。

## 7. 对比实验

对比实验用于证明本文方法整体有效。

表格通常包括：

- 不同方法。
- 多个评价指标。
- 最优结果加粗。
- 次优结果可下划线。

写作时要分析：

- 本文方法是否整体最好。
- 哪些指标提升最明显。
- 为什么会提升。
- 哪些场景提升不明显。

## 8. 消融实验

消融实验用于证明每个模块有贡献。

常见形式：

```text
完整模型
去掉模块 A
去掉模块 B
去掉模块 A 和 B
替换模块 C
```

论文中必须说明：

- 每个模块对应什么设计。
- 去掉后性能变化。
- 性能变化说明什么。

消融实验是支撑创新点的重要证据。

## 9. 参数敏感性实验

参数敏感性实验用于分析关键超参数对模型效果的影响。

常见参数：

- 学习率。
- batch size。
- hidden dimension。
- dropout rate。
- 损失函数权重。
- 树深度。
- SVM 的 C 和 gamma。

展示方式：

- 折线图。
- 柱状图。
- 表格。

结论要说明：

- 模型对参数是否敏感。
- 最优参数如何选择。
- 参数变化是否符合预期。

## 10. 复杂度分析

如果方法增加了模块，需要分析成本。

常见指标：

- 参数量。
- FLOPs。
- 训练时间。
- 推理时间。
- 显存占用。

论文中不能只说效果提升，也要说明代价是否可接受。

## 11. 可视化分析

可视化能增强论文说服力。

常见可视化：

- 混淆矩阵。
- ROC 曲线。
- PR 曲线。
- loss 曲线。
- t-SNE/UMAP 特征分布。
- Grad-CAM 热力图。
- Attention 权重图。
- 错误样本案例。

注意：

- 图要服务结论。
- 不要为了好看而放无关图。

## 12. 可复现性

论文实验要尽量可复现。

需要记录：

- 数据集版本。
- 数据划分方式。
- 随机种子。
- 硬件环境。
- 软件版本。
- 模型结构。
- 超参数。
- 训练轮数。
- early stopping 策略。

建议：

```text
所有实验在相同数据划分和相同硬件环境下进行。
```

## 13. 结果分析写法

不要只写“本文方法最好”。

更好的分析方式：

```text
从表中可以看出，本文方法在 F1-score 和 Recall 上分别较最优对比方法提升了 X 和 Y。这说明所提出模块能够更好地识别少数类样本，降低漏检率。
```

要包含：

- 指标变化。
- 对比对象。
- 原因解释。
- 和研究问题的对应关系。

## 14. 相关工作写法

相关工作不是简单罗列论文。

应按主题组织：

- 传统机器学习方法。
- 深度学习方法。
- 注意力机制相关方法。
- 当前方法的不足。

每一类要总结：

- 代表方法。
- 主要思想。
- 优点。
- 局限。
- 和本文工作的关系。

## 15. 方法章节写法

方法章节要讲清楚：

- 整体框架。
- 输入和输出。
- 每个模块的作用。
- 核心公式。
- 损失函数。
- 训练流程。
- 推理流程。

建议结构：

```text
3.1 问题定义
3.2 整体框架
3.3 核心模块
3.4 损失函数
3.5 训练与推理
```

## 16. 摘要写法

摘要通常包含：

- 研究背景。
- 现有方法问题。
- 本文方法。
- 实验结果。
- 结论意义。

避免：

- 只写背景，不写方法。
- 只说“效果较好”，不给具体提升。
- 使用过多空泛词。

## 17. 创新点写法

创新点要具体。

不够好：

```text
本文提出了一种新的深度学习方法。
```

更好：

```text
本文设计了一种融合局部卷积特征与全局注意力特征的分类模型，用于提升复杂背景下的目标识别能力。
```

创新点最好能被实验验证。

## 18. 局限性

论文可以写局限性，这不会削弱论文，反而显得严谨。

常见局限：

- 数据集规模有限。
- 只在单一场景验证。
- 计算成本较高。
- 对某些类别效果不足。
- 泛化到其他数据集仍需验证。

## 19. 常见错误

- 没有 baseline。
- 只和很弱的方法比。
- 测试集参与调参。
- 只报告 Accuracy。
- 没有消融实验。
- 没有说明数据划分。
- 超参数不透明。
- 图表没有分析。
- 结果提升很小但结论写得过强。
- 相关工作只罗列，不总结不足。

## 20. 论文实验检查清单

实验前：

- 研究问题是否明确。
- 数据集是否清楚。
- baseline 是否合理。
- 指标是否匹配任务。

实验中：

- 是否固定随机种子。
- 是否记录超参数。
- 是否保存最优模型。
- 是否避免数据泄漏。

实验后：

- 是否有对比实验。
- 是否有消融实验。
- 是否有参数敏感性分析。
- 是否有错误案例分析。
- 是否报告 mean ± std。
- 是否说明局限性。

## 21. 记忆重点

- 论文实验的核心是证明方法有效、稳定、可解释、可复现。
- baseline 必须公平合理。
- 消融实验支撑创新点。
- 参数敏感性实验说明模型鲁棒性。
- 结果分析要解释为什么提升。
- 可复现性是论文可信度的重要部分。
