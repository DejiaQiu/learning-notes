# 优化方法与损失函数

## 1. 为什么要学习优化

机器学习训练本质上是优化问题：

```text
寻找一组参数，使损失函数最小
```

论文中描述模型方法时，通常需要写清楚：

- 优化目标是什么。
- 损失函数是什么。
- 参数如何更新。
- 使用了什么正则化。
- 如何避免过拟合。

## 2. 经验风险最小化

模型无法直接优化真实总体风险，只能优化训练集上的平均损失。

```text
min (1/n) * sum(L(y_i, f(x_i)))
```

这叫经验风险最小化。

问题：

- 训练集风险低，不代表测试集风险低。
- 如果模型太复杂，可能过拟合。

## 3. 结构风险最小化

结构风险最小化在经验风险基础上加入模型复杂度惩罚。

```text
目标 = 训练损失 + 正则化项
```

例如：

```text
Loss = MSE + lambda * ||w||^2
```

目的：

- 控制模型复杂度。
- 提高泛化能力。

## 4. 常见损失函数

### 4.1 MSE

均方误差，常用于回归。

```text
MSE = mean((y - y_pred)^2)
```

特点：

- 对大误差惩罚重。
- 对异常值敏感。

### 4.2 MAE

平均绝对误差。

```text
MAE = mean(|y - y_pred|)
```

特点：

- 更鲁棒。
- 梯度在 0 点不连续。

### 4.3 Huber Loss

结合 MSE 和 MAE。

小误差用平方，大误差用绝对值。

适合存在异常值的回归任务。

### 4.4 二分类交叉熵

用于二分类。

```text
Loss = -[y log(p) + (1-y) log(1-p)]
```

### 4.5 多分类交叉熵

用于多分类，通常和 Softmax 搭配。

```text
Loss = -sum(y_i log(p_i))
```

### 4.6 Hinge Loss

SVM 常用损失。

```text
Loss = max(0, 1 - y*f(x))
```

目标是让样本不但分类正确，而且离边界有足够间隔。

### 4.7 Focal Loss

常用于类别不平衡任务。

作用：

- 降低容易样本的权重。
- 强调难分类样本。

在目标检测中很常见。

## 5. 梯度下降

梯度表示损失函数上升最快的方向。

梯度下降沿着负梯度方向更新参数。

```text
theta = theta - learning_rate * gradient
```

学习率控制每次走多远。

## 6. 批量梯度下降

每次使用全部训练数据计算梯度。

优点：

- 梯度稳定。

缺点：

- 大数据上计算慢。
- 内存开销大。

## 7. 随机梯度下降

每次使用一个样本计算梯度。

优点：

- 更新快。
- 有随机性，可能跳出局部区域。

缺点：

- 梯度噪声大。
- 损失曲线震荡。

## 8. Mini-batch 梯度下降

每次使用一小批样本。

这是深度学习中最常用方式。

优点：

- 计算效率高。
- 梯度比单样本稳定。
- 适合 GPU 并行。

## 9. Momentum

Momentum 引入历史梯度方向，减少震荡。

直观理解：

```text
当前更新方向 = 当前梯度 + 过去更新方向的一部分
```

适合损失函数地形狭长、震荡明显的情况。

## 10. RMSProp

RMSProp 根据历史梯度平方调整每个参数的学习率。

特点：

- 对频繁变化的参数使用较小步长。
- 对变化较少的参数使用较大步长。

## 11. Adam

Adam 结合 Momentum 和 RMSProp。

优点：

- 收敛快。
- 默认参数通常可用。
- 深度学习中非常常见。

常见默认参数：

```text
learning_rate = 0.001
beta1 = 0.9
beta2 = 0.999
```

## 12. AdamW

AdamW 改进了 Adam 中 weight decay 的处理方式。

在 Transformer、CNN 等深度模型中很常用。

## 13. 学习率

学习率是最重要的超参数之一。

学习率太大：

- 损失震荡。
- 训练发散。

学习率太小：

- 收敛很慢。
- 容易停在较差区域。

常见策略：

- 固定学习率。
- 阶梯衰减。
- 余弦退火。
- Warmup。
- ReduceLROnPlateau。

## 14. 凸优化与非凸优化

### 14.1 凸优化

凸问题通常只有全局最优，没有局部最优陷阱。

线性回归、逻辑回归在常见设置下是凸优化问题。

### 14.2 非凸优化

深度神经网络通常是非凸优化问题。

特点：

- 可能有多个局部最优。
- 可能有鞍点。
- 初始化和优化器会影响结果。

## 15. 正则化

正则化是控制模型复杂度的重要方法。

常见方式：

- L1 正则。
- L2 正则。
- Dropout。
- Early Stopping。
- 数据增强。
- 模型集成。

## 16. 约束优化

有些模型训练带约束条件，例如 SVM。

常见工具：

- 拉格朗日乘子法。
- KKT 条件。
- 对偶问题。

研究生论文中不一定要完整推导，但要理解：

- 约束优化不是直接无条件最小化。
- 对偶形式有时更容易求解。
- SVM 的支持向量来自 KKT 条件。

## 17. 论文中如何写优化目标

一个完整方法通常要说明：

```text
给定训练集 D = {(x_i, y_i)}，本文通过最小化如下目标函数训练模型：

L = L_task + lambda * L_reg
```

其中：

- L_task 是任务损失。
- L_reg 是正则化项。
- lambda 是权重系数。

如果有多个损失：

```text
L = L_cls + alpha * L_aux + beta * L_reg
```

必须解释 alpha、beta 的作用，并在实验中说明如何选择。

## 18. 记忆重点

- 机器学习训练就是优化损失函数。
- MSE 常用于回归，交叉熵常用于分类，Hinge Loss 常用于 SVM。
- 正则化用于控制模型复杂度。
- 学习率对训练影响极大。
- Adam 默认好用，AdamW 在深度学习中更常见。
- 深度学习通常是非凸优化问题。
- 论文要写清楚优化目标和损失函数组成。
