# 深度学习论文实验与复现

## 1. 为什么要重视实验复现

深度学习论文不仅要提出模型，还要证明模型有效、稳定、可复现。

复现能力包括：

- 能读懂论文方法。
- 能找到关键实现细节。
- 能搭建训练流程。
- 能复现实验指标。
- 能分析和原论文差距。

## 2. 读论文的顺序

建议顺序：

1. 摘要：看研究问题和主要结论。
2. Introduction：看动机和贡献。
3. Method：看模型结构和损失函数。
4. Experiments：看数据集、baseline、指标。
5. Ablation：看每个模块是否有效。
6. Appendix 或代码：看训练细节。

不要一开始就陷入公式细节，先抓整体框架。

## 3. 复现前要提取的信息

需要记录：

- 数据集。
- 数据划分。
- 输入尺寸。
- 数据增强。
- 模型结构。
- backbone。
- 预训练权重。
- optimizer。
- learning rate。
- batch size。
- epoch。
- loss function。
- scheduler。
- evaluation metric。
- random seed。

## 4. Baseline

深度学习论文中的 baseline 要公平。

公平比较要求：

- 相同数据划分。
- 相同输入尺寸。
- 相同评价指标。
- 相同训练轮数或充分收敛。
- baseline 参数合理。

不能只和明显弱的方法比较。

## 5. 消融实验

消融实验用于证明每个模块有效。

常见消融：

- 去掉 attention 模块。
- 去掉多尺度特征。
- 去掉辅助损失。
- 替换 backbone。
- 不使用预训练。
- 不使用某种数据增强。

写作逻辑：

```text
完整模型效果最好，去掉模块后效果下降，说明该模块有效。
```

## 6. 参数敏感性实验

参数敏感性实验用于说明模型对关键超参数是否稳定。

常见参数：

- learning rate。
- dropout rate。
- hidden dimension。
- loss weight。
- attention head 数。
- Transformer 层数。
- 输入图像分辨率。

展示方式：

- 折线图。
- 柱状图。
- 表格。

## 7. 复杂度分析

深度学习论文不能只报告精度。

常见复杂度指标：

- 参数量。
- FLOPs。
- 训练时间。
- 推理时间。
- 显存占用。
- FPS。

特别是目标检测、分割、移动端模型，要关注速度和资源消耗。

## 8. 可视化分析

常用可视化：

- loss 曲线。
- accuracy 曲线。
- 混淆矩阵。
- ROC 曲线。
- PR 曲线。
- t-SNE。
- Grad-CAM。
- Attention map。
- 错误样本展示。

可视化要服务论点，不要只为了好看。

## 9. 结果表格

结果表格建议包含：

- 方法名。
- 主要指标。
- 参数量或 FLOPs。
- 最优结果加粗。
- 次优结果下划线。

表格后要分析：

- 本文方法在哪些指标提升。
- 提升是否显著。
- 可能原因是什么。
- 哪些指标没有提升。

## 10. 多次运行

深度学习实验受随机种子影响。

建议：

```text
重复运行 3 到 5 次，报告 mean ± std。
```

如果计算资源不足，至少固定随机种子，并说明实验设置。

## 11. 复现结果不一致的原因

常见原因：

- 数据划分不同。
- 数据增强不同。
- 预训练权重不同。
- 学习率策略不同。
- batch size 不同。
- epoch 不同。
- 随机种子不同。
- 指标计算方式不同。
- 代码中隐藏实现细节。

## 12. 实验日志

建议记录：

- git commit。
- 配置文件。
- 数据版本。
- 环境版本。
- 训练日志。
- checkpoint。
- 最终指标。
- 随机种子。

工具：

- TensorBoard。
- Weights & Biases。
- MLflow。
- CSV。

## 13. 方法章节写作

方法章节要包含：

- 问题定义。
- 整体框架。
- 输入输出。
- 核心模块。
- 损失函数。
- 训练过程。
- 推理过程。

结构示例：

```text
3.1 Problem Definition
3.2 Overall Architecture
3.3 Feature Extraction Module
3.4 Attention Fusion Module
3.5 Loss Function
```

## 14. 实验章节写作

实验章节通常包含：

```text
4.1 Datasets
4.2 Evaluation Metrics
4.3 Implementation Details
4.4 Comparison with State-of-the-Art
4.5 Ablation Study
4.6 Parameter Analysis
4.7 Visualization and Case Study
```

## 15. Implementation Details

这一节非常重要。

需要说明：

- 框架，例如 PyTorch。
- GPU 型号。
- optimizer。
- 初始学习率。
- batch size。
- epoch。
- 输入尺寸。
- 数据增强。
- scheduler。
- loss function。
- random seed。

## 16. 常见论文问题

- 没有说明数据划分。
- 没有 implementation details。
- baseline 不公平。
- 只报告最优单次结果。
- 没有消融实验。
- 没有复杂度分析。
- 指标和任务不匹配。
- 结论超过实验支持范围。

## 17. 复现检查清单

复现前：

- 是否找到官方代码。
- 是否明确数据集版本。
- 是否明确预训练权重。
- 是否明确指标计算方式。

复现中：

- 是否固定随机种子。
- 是否记录配置。
- 是否保存 checkpoint。
- 是否观察 loss 曲线。

复现后：

- 指标是否接近论文。
- 差距可能来自哪里。
- 是否做了消融验证。
- 是否记录失败尝试。

## 18. 记忆重点

- 深度学习论文要证明有效、稳定、可解释、可复现。
- 消融实验是证明模块贡献的关键。
- Implementation Details 决定别人能否复现。
- 公平 baseline 比单纯追求高指标更重要。
- 复杂度分析能说明方法是否实用。
- 结果分析要解释提升原因和局限性。
