# 优化器与学习率策略

## 1. 优化器的作用

优化器根据梯度更新模型参数，使损失函数下降。

基本形式：

```text
参数 = 参数 - 学习率 * 梯度
```

优化器决定参数如何更新，学习率决定每次更新的步长。

## 2. SGD

SGD 是随机梯度下降。

优点：

- 简单。
- 泛化能力常常不错。
- 适合大规模数据。

缺点：

- 收敛可能较慢。
- 损失曲线容易震荡。

PyTorch 示例：

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

## 3. Momentum

Momentum 在 SGD 中加入动量。

直观理解：

```text
不仅看当前梯度，也保留过去更新方向
```

优点：

- 减少震荡。
- 加速收敛。
- 对狭长谷地优化更稳定。

示例：

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01,
    momentum=0.9,
)
```

## 4. RMSProp

RMSProp 根据历史梯度平方调整每个参数的学习率。

适合：

- 非平稳目标。
- 梯度尺度差异较大的参数。

现在常被 Adam 替代，但理解它有助于理解自适应学习率。

## 5. Adam

Adam 结合 Momentum 和 RMSProp 的思想。

它维护：

- 一阶矩估计：类似动量。
- 二阶矩估计：类似梯度平方的滑动平均。

优点：

- 收敛快。
- 默认参数通常好用。
- 深度学习中使用非常广泛。

常用默认值：

```text
lr = 0.001
beta1 = 0.9
beta2 = 0.999
```

示例：

```python
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
```

## 6. AdamW

AdamW 是 Adam 的改进版本，主要改进 weight decay。

在 Transformer、ViT、BERT、GPT 等模型中常用。

示例：

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    weight_decay=0.01,
)
```

## 7. 学习率的重要性

学习率太大：

- loss 震荡。
- 训练发散。
- 指标不稳定。

学习率太小：

- 收敛很慢。
- 训练不充分。
- 容易停在较差区域。

建议：

- 先从常用值开始。
- 观察 train loss 曲线。
- 必要时做学习率搜索。

## 8. 学习率衰减

训练初期需要较大学习率快速下降。

训练后期需要较小学习率精细收敛。

这就是学习率衰减的动机。

## 9. StepLR

每隔固定 epoch 降低学习率。

```python
scheduler = torch.optim.lr_scheduler.StepLR(
    optimizer,
    step_size=30,
    gamma=0.1,
)
```

含义：

- 每 30 个 epoch，学习率乘以 0.1。

## 10. Cosine Annealing

余弦退火让学习率按余弦曲线逐渐降低。

特点：

- 下降平滑。
- 常用于 CNN 和 Transformer。

```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=100,
)
```

## 11. ReduceLROnPlateau

当验证集指标不再提升时降低学习率。

```python
scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(
    optimizer,
    mode="min",
    factor=0.1,
    patience=5,
)
```

适合不知道什么时候该降学习率的场景。

## 12. Warmup

Warmup 在训练初期逐渐增大学习率。

作用：

- 避免训练初期不稳定。
- 常用于 Transformer 和大模型。

常见策略：

```text
前几个 epoch 或 step 线性增大学习率
之后再进行衰减
```

## 13. Batch Size

batch size 会影响：

- 显存占用。
- 梯度噪声。
- 收敛速度。
- 泛化能力。

batch size 大：

- 训练稳定。
- 显存占用大。
- 泛化可能变差。

batch size 小：

- 梯度噪声大。
- 训练不稳定。
- 有时泛化更好。

## 14. 梯度累积

显存不足时，可以用梯度累积模拟大 batch。

思想：

```text
多个小 batch 累积梯度，再更新一次参数
```

适合大模型训练。

## 15. 优化器选择建议

常见选择：

- CNN 图像分类：SGD + Momentum 或 AdamW。
- Transformer：AdamW。
- 快速实验：Adam。
- 追求最终泛化：可以比较 SGD 和 AdamW。

## 16. 记忆重点

- 优化器决定参数更新方式，学习率决定更新步长。
- SGD 简单，泛化常常不错。
- Adam 收敛快，默认易用。
- AdamW 是当前深度学习常用优化器。
- 学习率策略对最终效果影响很大。
- Warmup 常用于 Transformer。
- batch size 会影响显存、稳定性和泛化。
