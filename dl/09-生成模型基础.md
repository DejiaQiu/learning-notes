# 生成模型基础

## 1. 什么是生成模型

生成模型学习数据分布，并从中生成新样本。

常见任务：

- 图像生成。
- 文本生成。
- 数据增强。
- 图像修复。
- 超分辨率。
- 风格迁移。
- 异常检测。

和判别模型对比：

```text
判别模型：学习 P(y|x)
生成模型：学习 P(x) 或 P(x, y)
```

## 2. AutoEncoder

AutoEncoder 自编码器由 Encoder 和 Decoder 组成。

结构：

```text
输入 x -> Encoder -> latent z -> Decoder -> 重构 x'
```

训练目标：

```text
让 x' 尽可能接近 x
```

常见用途：

- 降维。
- 去噪。
- 异常检测。
- 特征学习。

## 3. Denoising AutoEncoder

去噪自编码器输入被加噪声的数据，目标是恢复原始数据。

作用：

- 学习更鲁棒的表示。
- 用于图像去噪。

## 4. VAE

VAE 全称 Variational AutoEncoder，变分自编码器。

和普通 AutoEncoder 的区别：

- Encoder 输出的是分布参数。
- 从 latent distribution 中采样 z。
- Decoder 从 z 重构数据。

VAE 损失通常包括：

```text
重构损失 + KL 散度
```

## 5. VAE 的优缺点

优点：

- 有概率解释。
- latent space 连续。
- 可以生成新样本。

缺点：

- 生成图像容易模糊。
- 训练和推导比普通 AE 复杂。

## 6. GAN

GAN 全称 Generative Adversarial Network。

由两个网络组成：

- Generator：生成假样本。
- Discriminator：判断样本真假。

训练过程：

```text
生成器努力骗过判别器
判别器努力区分真实样本和生成样本
```

## 7. GAN 的目标

理想状态：

- 生成器生成的数据接近真实数据。
- 判别器无法区分真假。

GAN 是一种对抗训练框架。

## 8. GAN 优点

- 能生成清晰样本。
- 图像生成效果强。
- 可用于风格迁移、超分辨率等任务。

## 9. GAN 缺点

- 训练不稳定。
- 容易 mode collapse。
- 评价困难。
- 对超参数敏感。

## 10. 常见 GAN 变体

- DCGAN：使用 CNN 的 GAN。
- WGAN：改进训练稳定性。
- CycleGAN：无配对图像转换。
- StyleGAN：高质量人脸生成。

## 11. Diffusion Model

扩散模型是当前重要生成模型。

核心思想：

1. 前向过程逐步给数据加噪声。
2. 反向过程学习逐步去噪。
3. 从纯噪声开始生成样本。

## 12. Diffusion 的优点

- 生成质量高。
- 训练相对稳定。
- 多样性好。
- 是很多图像生成模型的基础。

## 13. Diffusion 的缺点

- 采样速度慢。
- 计算成本高。
- 模型结构和训练流程较复杂。

## 14. 条件生成

条件生成是在生成过程中加入条件信息。

条件可以是：

- 类别标签。
- 文本描述。
- 图像。
- 边缘图。
- 分割图。

例子：

```text
根据文本生成图像
根据低分辨率图像生成高分辨率图像
根据草图生成真实图像
```

## 15. 生成模型评价

图像生成常用指标：

- FID。
- IS。
- LPIPS。

但生成质量也需要人工评估。

注意：

- 指标不能完全代表视觉质量。
- 不同论文的评估设置要一致才公平。

## 16. 生成模型和论文

论文中使用生成模型时要说明：

- 生成任务是什么。
- 训练数据是什么。
- 条件信息是什么。
- 损失函数是什么。
- 如何评价生成质量。
- 是否存在生成偏差或不真实样本。

## 17. 记忆重点

- AutoEncoder 学习重构。
- VAE 学习 latent distribution。
- GAN 使用生成器和判别器对抗训练。
- Diffusion 通过加噪和去噪生成样本。
- GAN 生成清晰但训练不稳定。
- Diffusion 质量高但采样成本大。
