# 前馈神经网络

## 1. 本章目标

前馈神经网络是最基础的神经网络结构。后面的 CNN、RNN、注意力模型都可以看成在信息连接方式或结构假设上的扩展。

需要掌握：

- 神经元的计算过程。
- 激活函数为什么必要。
- 前馈网络如何组合成复杂函数。
- 反向传播如何计算梯度。
- 网络容量、深度和非线性之间的关系。

## 2. 神经元

一个神经元通常做两步：

```text
z = w^T x + b
a = phi(z)
```

其中：

- `z` 是净输入。
- `phi` 是激活函数。
- `a` 是神经元输出。

可以把神经元理解为“先做线性打分，再通过非线性门”。

## 3. 激活函数

激活函数提供非线性表达能力。

常见激活函数：

- Sigmoid：输出在 `(0, 1)`，适合概率解释，但容易梯度消失。
- Tanh：输出在 `(-1, 1)`，中心化比 Sigmoid 好。
- ReLU：`max(0, x)`，简单高效，是常用隐藏层激活。
- Leaky ReLU：缓解 ReLU 死亡问题。
- GELU/Swish：更平滑，常用于现代深层模型。

如果隐藏层没有非线性，多层网络会退化为单层线性模型。

## 4. 网络结构

前馈网络的信息单向流动：

```text
输入层 -> 隐藏层 1 -> 隐藏层 2 -> ... -> 输出层
```

全连接前馈网络中，每一层的每个神经元都接收上一层所有神经元输出。

第 `l` 层可以写成：

```text
z_l = W_l a_{l-1} + b_l
a_l = phi_l(z_l)
```

## 5. 输出层设计

输出层取决于任务：

- 回归：线性输出。
- 二分类：Sigmoid 输出概率。
- 多分类：Softmax 输出类别概率。
- 多标签分类：每个标签一个 Sigmoid。

输出层和损失函数要匹配。多分类常用 Softmax + 交叉熵；回归常用线性输出 + 均方误差。

## 6. 前向传播

前向传播是从输入到输出的计算过程：

```text
x -> z_1 -> a_1 -> z_2 -> a_2 -> y_hat -> loss
```

训练时前向传播会保存中间变量，因为反向传播需要它们计算梯度。

## 7. 反向传播

反向传播本质是链式法则在计算图上的高效应用。

核心思想：

```text
当前梯度 = 上游梯度 * 局部梯度
```

训练一个前馈网络通常分三步：

1. 前向计算每层输出和损失。
2. 从损失开始反向计算每层误差项和梯度。
3. 用优化算法更新参数。

## 8. 误差项直觉

每一层的误差项可以理解为：

```text
这一层的输出变化，会让最终损失变化多少
```

靠近输出层的误差容易直接计算，前面层的误差通过后一层反传得到。

这解释了为什么反向传播不是“试错”，而是系统地把最终误差信号分配给每一层参数。

## 9. 网络容量

影响网络表达能力的因素：

- 隐藏层数量。
- 每层神经元数量。
- 激活函数类型。
- 连接结构。
- 参数共享方式。

容量越大，拟合能力越强，但过拟合风险也越高。深度学习的目标不是堆最大网络，而是在表达能力、优化难度和泛化之间平衡。

## 10. 梯度消失和爆炸

深层网络中，梯度要经过多层连乘。

如果每层局部梯度普遍小于 1，梯度会快速变小，形成梯度消失。如果局部梯度普遍大于 1，梯度可能快速变大，形成梯度爆炸。

常见缓解方法：

- 使用 ReLU 类激活。
- 合理初始化。
- 归一化层。
- 残差连接。
- 梯度裁剪。

## 11. 易错点

- 把神经元画法当成神经网络的本质。实际本质是参数化函数和可微优化。
- 认为网络越深一定越好。深层网络还要能训练、能泛化。
- 忘记输出层和损失函数必须匹配。
- 只背反向传播公式，不理解链式法则和计算图。
- 把隐藏层输出直接解释成人类可读特征，很多时候它只是任务相关表示。

## 12. 自测题

1. 为什么神经网络必须有非线性激活函数。
2. 前向传播和反向传播分别计算什么。
3. Softmax 输出层适合什么任务。
4. 梯度消失为什么会影响前面层学习。
5. 网络容量增大时，训练误差和测试误差可能怎样变化。
