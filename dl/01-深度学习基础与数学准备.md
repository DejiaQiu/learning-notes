# 深度学习基础与数学准备

## 1. 深度学习是什么

深度学习是机器学习的一个分支，使用多层神经网络从数据中学习特征和模式。

和传统机器学习相比，深度学习的特点是：

- 可以自动学习特征。
- 适合图像、文本、语音、视频等复杂数据。
- 通常需要更多数据和计算资源。
- 模型可解释性相对较弱。

## 2. 张量

张量是深度学习中的基本数据结构。

常见维度：

```text
标量：0 维，例如 loss
向量：1 维，例如 [1, 2, 3]
矩阵：2 维，例如 batch x feature
三维张量：例如 batch x seq_len x hidden
四维张量：例如 batch x channel x height x width
```

PyTorch 中图像常用格式：

```text
N x C x H x W
batch x channel x height x width
```

## 3. 矩阵乘法

神经网络中的全连接层本质上是矩阵乘法。

```text
Y = XW + b
```

其中：

- X：输入。
- W：权重矩阵。
- b：偏置。
- Y：输出。

如果：

```text
X: batch_size x input_dim
W: input_dim x output_dim
```

则：

```text
Y: batch_size x output_dim
```

## 4. 激活函数

如果没有激活函数，多层线性变换仍然等价于一层线性变换。

激活函数提供非线性能力。

常见激活函数：

- Sigmoid。
- Tanh。
- ReLU。
- Leaky ReLU。
- GELU。
- Softmax。

## 5. ReLU

ReLU 是最常见隐藏层激活函数。

```text
ReLU(x) = max(0, x)
```

优点：

- 计算简单。
- 缓解梯度消失。
- 收敛速度快。

缺点：

- 可能出现 dead ReLU。

## 6. GELU

GELU 常用于 Transformer。

它比 ReLU 更平滑，可以理解为带概率门控的激活函数。

BERT、GPT 等模型中经常使用 GELU。

## 7. Softmax

Softmax 把多个类别得分转换成概率。

```text
p_i = exp(z_i) / sum(exp(z_j))
```

特点：

- 输出都大于 0。
- 所有类别概率之和为 1。
- 常和交叉熵损失搭配。

## 8. 损失函数

损失函数衡量预测结果和真实标签之间的差距。

常见损失：

- 回归：MSE、MAE、Huber Loss。
- 二分类：Binary Cross Entropy。
- 多分类：Cross Entropy。
- 检测：分类损失 + 边框回归损失。
- 分割：Cross Entropy、Dice Loss、IoU Loss。

## 9. 梯度

梯度表示函数在当前位置变化最快的方向。

训练神经网络时，优化器会沿负梯度方向更新参数。

```text
参数 = 参数 - 学习率 * 梯度
```

## 10. 链式法则

反向传播的数学基础是链式法则。

如果：

```text
y = f(u)
u = g(x)
```

则：

```text
dy/dx = dy/du * du/dx
```

神经网络由很多层函数复合而成，所以可以用链式法则逐层计算梯度。

## 11. MLP

MLP 是多层感知机，由多个全连接层组成。

结构：

```text
输入 -> Linear -> 激活 -> Linear -> 激活 -> 输出
```

适合：

- 表格特征。
- 已经提取好的向量特征。
- 简单分类和回归任务。

不适合：

- 大尺寸图像直接输入。
- 长序列直接输入。

## 12. 前向传播

前向传播是从输入计算预测值的过程。

```text
x -> layer1 -> layer2 -> ... -> y_pred
```

## 13. 反向传播

反向传播是从损失函数开始，反向计算每个参数梯度的过程。

训练循环：

```text
前向传播 -> 计算损失 -> 反向传播 -> 参数更新
```

## 14. 参数和超参数

参数是训练中自动学习的：

- 权重。
- 偏置。
- BatchNorm 中的可学习参数。

超参数是训练前人为设置的：

- 学习率。
- batch size。
- epoch 数。
- 网络层数。
- hidden dimension。
- dropout rate。

## 15. 深度学习常见任务

图像：

- 图像分类。
- 目标检测。
- 语义分割。
- 实例分割。

文本：

- 文本分类。
- 序列标注。
- 问答。
- 摘要。
- 机器翻译。

序列：

- 时间序列预测。
- 异常检测。
- 行为识别。

图数据：

- 节点分类。
- 链接预测。
- 图分类。

## 16. 记忆重点

- 张量是深度学习中的基本数据结构。
- 全连接层本质是矩阵乘法。
- 激活函数提供非线性能力。
- 反向传播依赖链式法则。
- 训练目标是最小化损失函数。
- 深度学习适合复杂非结构化数据，但需要更多数据和计算资源。
