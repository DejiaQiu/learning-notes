# 绪论

## 1. 本章目标

这一章不是讲具体算法，而是建立深度学习的整体坐标系。

需要回答五个问题：

- 人工智能、机器学习、深度学习、神经网络是什么关系。
- 为什么“表示”是深度学习的核心。
- 深度学习为什么在近年重新兴起。
- 神经网络的发展经历了哪些关键阶段。
- 学完整本书后，知识体系应该怎样展开。

## 2. AI、ML、DL、NN 的关系

可以按包含关系理解：

```text
人工智能 AI
└── 机器学习 ML
    ├── 传统机器学习
    └── 深度学习 DL
        └── 以神经网络为主要模型
```

人工智能关注“让机器表现出智能行为”。机器学习关注“让机器从数据中学习规律”。深度学习关注“用多层表示学习复杂函数和特征”。神经网络是深度学习最主要的模型形式。

不要把深度学习等同于全部人工智能。深度学习解决的是一大类从数据中学习表示和映射的问题，但推理、规划、知识表示、交互决策等问题仍然需要更多方法配合。

## 3. 机器学习的基本思想

机器学习的基本流程是：

```text
数据 -> 特征/表示 -> 模型 -> 预测 -> 损失 -> 参数更新
```

传统机器学习经常依赖人工设计特征。例如图像任务中先提边缘、纹理、形状，再送入分类器。

深度学习的变化在于：特征表示也由模型从数据中学习。低层可以学习边缘和局部模式，高层可以组合成更抽象的语义特征。

## 4. 表示学习

表示学习关注如何把原始数据变成适合模型处理的形式。

一个好的表示应该具备：

- 能保留任务相关信息。
- 能去掉无关噪声。
- 能让后续模型更容易学习。
- 能在相似样本之间形成相似的向量结构。

局部表示通常用少量符号或 one-hot 形式表达对象，直观但泛化弱。分布式表示用向量的多个维度共同表达对象，能表达更多相似性和组合关系。

## 5. 深度学习的核心

深度学习的“深”不是简单地把层数堆高，而是通过多层非线性变换逐级抽象表示。

典型结构：

```text
原始输入 -> 低层特征 -> 中层特征 -> 高层语义 -> 输出
```

端到端学习是深度学习的重要特点：模型可以直接从输入学习到输出，减少手工中间环节。但端到端并不意味着不需要数据清洗、任务设计、评价指标和工程约束。

## 6. 为什么深度学习兴起

深度学习发展依赖几个条件同时成熟：

- 数据规模变大，模型有足够样本学习复杂规律。
- GPU 等硬件提升，使大规模矩阵计算变得可行。
- 激活函数、初始化、归一化、优化器等训练方法改进。
- 图像、语音、文本、推荐等应用场景推动实际需求。
- 开源框架降低了实现和复现实验的成本。

## 7. 神经网络的发展脉络

可以抓住几条线：

- 早期感知器证明了线性分类的可学习性。
- 多层网络能表达更复杂函数，但训练长期困难。
- 反向传播让多层网络训练变得系统化。
- 深度学习阶段依靠数据、算力和训练技巧扩展到大模型。

历史经验：模型能力不是唯一因素。训练算法、数据规模、计算平台和任务需求共同决定一个方向能否爆发。

## 8. 深度学习的能力边界

深度学习擅长：

- 从高维非结构化数据中学习表示。
- 在大量样本上拟合复杂映射。
- 通过预训练和迁移适配多种任务。
- 与端到端系统结合形成工程能力。

深度学习不天然擅长：

- 小数据下可靠泛化。
- 严格逻辑推理和因果解释。
- 对分布外样本保持稳定。
- 给出人类可直接理解的决策过程。

## 9. 学习本书的主线

本书可以看成三层：

```text
机器学习基础 -> 神经网络核心模型 -> 概率与生成/强化/序列进阶模型
```

学习时不要只记模型名称，而要围绕这些问题：

- 这个模型的输入、输出、参数是什么。
- 它假设了数据具有怎样的结构。
- 损失函数如何定义。
- 参数如何学习。
- 它解决了前一个模型的什么问题，又引入了什么新问题。

## 10. 易错点

- 把深度学习当成万能工具，忽略任务、数据和评价指标。
- 把神经网络理解成生物大脑的直接复刻。人工神经网络只是受启发的数学模型。
- 把端到端学习理解成不需要人工设计。实际仍需要设计目标函数、数据流程和训练策略。
- 只关注网络结构，忽略优化和泛化。
