# 注意力机制与外部记忆

## 1. 本章目标

注意力机制让模型在处理信息时动态选择重点。外部记忆机制让模型把信息存到可读写的记忆结构中。

需要掌握：

- 注意力的查询、键、值三元组。
- 加性注意力、点积注意力、自注意力。
- 多头注意力的作用。
- 外部记忆的读写直觉。
- 注意力和 RNN、CNN 的差异。

## 2. 为什么需要注意力

RNN 把历史压缩进隐藏状态，长序列时信息容易丢失。CNN 通过局部窗口捕捉模式，长距离依赖需要堆很多层。

注意力提供另一种思路：

```text
需要什么信息，就对所有候选信息计算相关性，再加权汇总
```

它不是固定窗口，也不是只依赖最后隐藏状态，而是动态地从上下文中选择。

## 3. QKV 框架

注意力可以用三类向量描述：

- Query：当前要查询什么。
- Key：候选信息的索引或匹配特征。
- Value：真正要读取的内容。

计算流程：

```text
score_i = similarity(query, key_i)
alpha_i = softmax(score_i)
context = sum_i alpha_i * value_i
```

`alpha_i` 是注意力权重，表示当前查询对第 `i` 个候选信息的关注程度。

## 4. 常见打分函数

常见注意力打分：

- 加性注意力：用小型神经网络计算 query 和 key 的匹配。
- 点积注意力：直接做向量点积。
- 缩放点积注意力：点积后除以维度平方根，避免数值过大。
- 双线性注意力：引入可学习矩阵计算匹配。

不同打分函数本质都在估计 query 和 key 的相关性。

## 5. 自注意力

自注意力中，query、key、value 都来自同一个序列。

它可以让序列中任意两个位置直接交互：

```text
每个位置 -> 看序列中所有位置 -> 汇总上下文表示
```

这让自注意力适合建模长距离依赖，也是 Transformer 的核心。

## 6. 多头注意力

多头注意力把表示分成多个子空间，分别计算注意力，再拼接。

直觉：

- 不同头可以关注不同关系。
- 一个头关注语法，一个头关注位置，一个头关注语义，是常见但不绝对的解释。
- 多头提升模型表达能力。

多头不是简单重复，而是让模型在多个投影空间中计算不同的匹配关系。

## 7. 注意力的优点

优点：

- 能直接建立远距离依赖。
- 权重可视化有一定解释价值。
- 比 RNN 更容易并行。
- 能与 CNN、RNN、外部记忆等结构组合。

局限：

- 标准自注意力计算量随序列长度平方增长。
- 注意力权重不等同于严格解释。
- 长上下文中仍可能出现信息干扰。

## 8. 外部记忆

外部记忆模型给网络提供一个显式的记忆矩阵：

```text
Memory = [m_1, m_2, ..., m_N]
```

模型可以：

- 读：根据查询从记忆中取信息。
- 写：把新信息写入记忆。
- 擦除或更新：修改已有记忆。

这类模型尝试增强神经网络的存储和推理能力。

## 9. 记忆网络直觉

记忆网络常用于问答类任务：

```text
事实句子 -> 写入记忆
问题 -> 查询记忆
相关记忆 -> 汇总 -> 答案
```

注意力在这里用于“从记忆中找相关事实”。如果需要多跳推理，模型可以多次读取记忆。

## 10. 和 RNN 的关系

RNN 的记忆是隐藏状态，容量有限且隐式压缩。外部记忆是显式存储，理论上可以保存更多信息。

注意力可以看成一种软寻址机制：不是选一个位置，而是对所有位置分配权重后加权读取。

## 11. 易错点

- 注意力权重高不一定等于人类解释中的因果重要性。
- 自注意力不是自动具备顺序感，通常需要位置编码或结构信息。
- 多头数越多不一定越好，过多会增加计算并可能冗余。
- 外部记忆不是数据库，读写仍然由可学习机制控制。
- 注意力解决长距离交互，但不解决所有泛化问题。
