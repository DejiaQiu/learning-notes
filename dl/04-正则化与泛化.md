# 正则化与泛化

## 1. 泛化能力

泛化能力指模型在未见过数据上的表现。

训练集效果好不代表模型好，验证集和测试集表现更重要。

常见问题：

- 欠拟合：训练集和测试集都差。
- 过拟合：训练集好，测试集差。

## 2. 过拟合原因

常见原因：

- 模型太复杂。
- 训练数据太少。
- 标签噪声大。
- 训练轮数太多。
- 数据增强不足。
- 数据划分有问题。

## 3. 权重衰减

权重衰减限制权重过大。

作用：

- 控制模型复杂度。
- 减少过拟合。

AdamW 示例：

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    weight_decay=0.01,
)
```

## 4. Dropout

Dropout 在训练时随机丢弃部分神经元。

作用：

- 减少神经元共适应。
- 提高模型鲁棒性。
- 降低过拟合。

注意：

- 训练时启用。
- 推理时关闭。
- dropout rate 太大可能欠拟合。

## 5. Batch Normalization

BatchNorm 对 batch 内的激活值做归一化。

常见结构：

```text
Conv -> BatchNorm -> ReLU
```

作用：

- 稳定训练。
- 加快收敛。
- 有轻微正则化效果。

注意：

- 训练和推理行为不同。
- 小 batch 时统计量可能不稳定。

## 6. Layer Normalization

LayerNorm 对单个样本的特征维度做归一化。

常用于：

- Transformer。
- NLP。
- 序列建模。

特点：

- 不依赖 batch size。
- 小 batch 下更稳定。

## 7. Early Stopping

Early Stopping 根据验证集表现提前停止训练。

逻辑：

```text
如果验证集指标连续若干轮不提升，就停止训练
```

常见参数：

- patience。
- min_delta。

优点：

- 防止训练过久导致过拟合。
- 节省计算资源。

## 8. 数据增强

数据增强通过变换训练样本增加数据多样性。

图像增强：

- Random Crop。
- Random Resized Crop。
- Horizontal Flip。
- Rotation。
- Color Jitter。
- Cutout。
- Mixup。
- CutMix。

文本增强：

- 随机删除。
- 同义词替换。
- 回译。
- token mask。

注意：

- 增强不能改变标签。
- 医学、工业、遥感等场景要结合业务判断。

## 9. Label Smoothing

Label Smoothing 把 one-hot 标签变得不那么绝对。

例如原始标签：

```text
[0, 1, 0]
```

平滑后：

```text
[0.05, 0.90, 0.05]
```

作用：

- 减少过度自信。
- 提高泛化能力。

## 10. Mixup

Mixup 把两个样本和标签线性混合。

```text
x = lambda*x1 + (1-lambda)*x2
y = lambda*y1 + (1-lambda)*y2
```

作用：

- 增强样本空间连续性。
- 减少过拟合。

## 11. CutMix

CutMix 把一张图像的一块区域替换成另一张图像的区域，同时按区域比例混合标签。

常用于图像分类。

优点：

- 保留局部真实图像块。
- 比普通 Mixup 更适合某些视觉任务。

## 12. 模型集成

集成多个模型可以提高稳定性和性能。

方式：

- 多模型平均。
- 多折模型融合。
- 不同随机种子模型融合。
- 不同结构模型融合。

缺点：

- 推理成本增加。
- 部署复杂。

## 13. 数据泄漏

深度学习中也会发生数据泄漏。

常见情况：

- 同一个病人图像同时出现在训练集和测试集。
- 视频帧随机切分，导致相邻帧进入不同集合。
- 先对全量数据做归一化，再划分数据集。
- 数据增强或缓存时混入测试数据。

避免方法：

- 先划分数据，再做统计。
- 按用户、病人、设备分组划分。
- 固定数据划分并记录。

## 14. 泛化检查

训练时要观察：

- train loss。
- val loss。
- train metric。
- val metric。

如果 train loss 下降、val loss 上升，说明可能过拟合。

如果 train loss 和 val loss 都很高，说明可能欠拟合。

## 15. 记忆重点

- 泛化能力是深度学习的核心目标。
- Dropout、weight decay、数据增强都能减少过拟合。
- BatchNorm 常用于 CNN，LayerNorm 常用于 Transformer。
- Early Stopping 通过验证集控制训练停止。
- 数据泄漏会让实验结果虚高。
- 论文实验必须说明正则化和数据增强设置。
