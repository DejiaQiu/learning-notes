# 计算图与反向传播

## 1. 什么是计算图

计算图是把数学计算表示成节点和边的图结构。

节点表示：

- 变量。
- 参数。
- 运算。

边表示：

- 数据流动方向。
- 依赖关系。

深度学习框架通过计算图自动计算梯度。

## 2. 一个简单计算图

假设：

```text
z = x * w + b
y = sigmoid(z)
loss = L(y, target)
```

计算图：

```text
x ----\
      multiply -> add -> sigmoid -> loss
w ----/          /
               b
```

前向传播计算 loss，反向传播计算 loss 对 x、w、b 的梯度。

## 3. 前向传播

前向传播按计算图方向从输入到输出执行。

作用：

- 计算中间变量。
- 得到模型预测。
- 计算损失。

前向传播会保存一些中间结果，供反向传播使用。

## 4. 反向传播

反向传播从 loss 出发，沿计算图反方向计算梯度。

核心：

```text
局部梯度 * 上游梯度 = 当前变量梯度
```

这就是链式法则在计算图上的应用。

## 5. 局部梯度

每个运算节点只需要知道自己输出对输入的导数。

例如：

```text
z = x * w
dz/dx = w
dz/dw = x
```

反向传播会把上游梯度乘上局部梯度，继续传给前面的节点。

## 6. 自动微分

PyTorch、TensorFlow 等框架使用自动微分。

自动微分不是数值微分，也不是符号求导。

特点：

- 根据实际计算过程构建计算图。
- 保存中间变量。
- 自动应用链式法则。
- 能高效计算梯度。

## 7. PyTorch 中的 autograd

PyTorch 使用动态计算图。

示例：

```python
import torch

x = torch.tensor([2.0], requires_grad=True)
w = torch.tensor([3.0], requires_grad=True)
b = torch.tensor([1.0], requires_grad=True)

y = x * w + b
loss = y ** 2

loss.backward()

print(x.grad)
print(w.grad)
print(b.grad)
```

只要 tensor 设置了 `requires_grad=True`，PyTorch 就会追踪相关运算。

## 8. 梯度清零

PyTorch 中梯度默认会累加。

每次参数更新前需要清零：

```python
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

如果忘记清零，梯度会叠加，导致训练异常。

## 9. detach

`detach()` 会把 tensor 从计算图中分离。

用途：

- 阻止梯度继续传播。
- 记录中间结果但不参与反向传播。
- 生成伪标签或 target 时避免梯度回传。

示例：

```python
y = model(x)
y_detached = y.detach()
```

## 10. no_grad

推理或验证阶段不需要计算梯度。

```python
model.eval()

with torch.no_grad():
    y_pred = model(x)
```

好处：

- 节省显存。
- 加快计算。
- 避免无意义梯度记录。

## 11. 梯度消失

梯度消失是指反向传播到前面层时梯度变得很小。

常见原因：

- 网络太深。
- 使用 Sigmoid 或 Tanh。
- 初始化不合适。

解决方法：

- ReLU。
- BatchNorm。
- 残差连接。
- 合理初始化。

## 12. 梯度爆炸

梯度爆炸是指梯度过大，导致参数更新不稳定。

常见于：

- RNN。
- 很深的网络。
- 学习率过大。

解决方法：

- 梯度裁剪。
- 降低学习率。
- 使用归一化层。
- 改进初始化。

## 13. 梯度裁剪

梯度裁剪限制梯度范数。

PyTorch 示例：

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

常用于 Transformer 和 RNN。

## 14. 动态图和静态图

动态图：

- 边运行边构图。
- 调试方便。
- PyTorch 典型使用动态图。

静态图：

- 先定义完整计算图，再执行。
- 适合图优化和部署。

## 15. 记忆重点

- 计算图描述变量和运算之间的依赖关系。
- 反向传播是链式法则在计算图上的应用。
- PyTorch 梯度默认累加，需要 `zero_grad()`。
- 验证和推理阶段要使用 `torch.no_grad()`。
- `detach()` 可以切断梯度传播。
- 梯度消失和梯度爆炸是深层网络训练的常见问题。
