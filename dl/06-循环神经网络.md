# 循环神经网络

## 1. 本章目标

循环神经网络用于处理序列数据。它的核心是用隐藏状态保存历史信息。

需要掌握：

- 序列建模任务的输入输出形式。
- RNN 的隐藏状态递推。
- 随时间反向传播 BPTT。
- 梯度消失和长程依赖问题。
- LSTM、GRU 如何用门控缓解问题。

## 2. 序列数据

序列数据的特点是元素之间有顺序依赖。

常见序列：

- 文本：词或字按顺序出现。
- 语音：声学帧随时间变化。
- 时间序列：传感器、金融、日志。
- 视频：帧序列。

同一个元素出现在不同位置，含义可能不同。因此序列模型需要考虑上下文。

## 3. RNN 基本形式

RNN 在每个时间步接收当前输入和上一步隐藏状态：

```text
h_t = phi(W_x x_t + W_h h_{t-1} + b)
y_t = g(W_y h_t + c)
```

其中：

- `x_t` 是第 `t` 步输入。
- `h_t` 是当前隐藏状态。
- `h_{t-1}` 保存历史信息。
- `y_t` 是当前输出。

RNN 的参数在不同时间步共享，因此可以处理变长序列。

## 4. 展开视角

RNN 可以沿时间展开成一个很深的前馈网络：

```text
x_1 -> h_1 -> y_1
x_2 -> h_2 -> y_2
x_3 -> h_3 -> y_3
...
```

每个时间步使用同一组参数。这个展开视角帮助理解 BPTT：反向传播不仅跨层传播，也跨时间传播。

## 5. 输入输出模式

常见任务形式：

- 一对一：普通分类或回归，不强调序列。
- 一对多：图像生成描述。
- 多对一：文本分类、情感分析。
- 多对多同步：序列标注、语音帧分类。
- 多对多异步：机器翻译、摘要生成。

设计模型前要先确定任务属于哪种输入输出模式。

## 6. BPTT

BPTT 是 Backpropagation Through Time，意思是沿时间展开后做反向传播。

问题在于：长序列会让梯度经过很多次连乘。

结果可能是：

- 梯度消失：早期时间步几乎学不到。
- 梯度爆炸：参数更新不稳定。

因此 RNN 在长程依赖任务上训练困难。

## 7. 长程依赖

长程依赖指当前输出依赖很早之前的信息。

例如句子：

```text
The book that the students read yesterday ...
```

后面的谓词可能需要依赖前面很远的主语。普通 RNN 很难稳定保留这类信息。

## 8. LSTM

LSTM 引入记忆单元和门控机制。

主要门：

- 遗忘门：决定旧记忆保留多少。
- 输入门：决定新信息写入多少。
- 输出门：决定当前记忆输出多少。

LSTM 的核心改进是让信息可以沿记忆单元更稳定地传播，缓解普通 RNN 的长程依赖问题。

## 9. GRU

GRU 是更简洁的门控循环单元。

主要门：

- 更新门：控制旧状态和新候选状态的混合。
- 重置门：控制计算候选状态时使用多少历史信息。

GRU 参数通常少于 LSTM，训练更轻量。实际任务中 LSTM 和 GRU 都需要通过验证集比较。

## 10. 双向 RNN

双向 RNN 同时使用前向和后向上下文：

```text
前向：x_1 -> x_2 -> ... -> x_T
后向：x_T -> x_{T-1} -> ... -> x_1
```

它适合序列标注、文本分类等可以看到完整输入的任务。

不适合严格在线预测场景，因为在线场景不能提前看到未来输入。

## 11. RNN 的局限

RNN 的问题：

- 长序列训练慢，难并行。
- 长程依赖仍然困难。
- 隐藏状态容量有限。
- 很深或很长时优化不稳定。

注意力机制和 Transformer 在很多序列任务上替代 RNN，主要原因之一就是能更直接地建模长距离依赖并提高并行效率。

## 12. 易错点

- 以为 RNN 只能处理文本。任何有顺序依赖的数据都可以尝试。
- 忘记 RNN 在时间步之间共享参数。
- 把隐藏状态当成完整记忆。它只是压缩后的历史表示。
- 双向 RNN 不能用于需要实时输出且不能看未来的任务。
- LSTM/GRU 缓解长程依赖，但不保证解决所有长序列问题。
