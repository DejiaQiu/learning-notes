# 无监督学习

## 1. 本章目标

无监督学习没有人工标签，目标是从数据本身发现结构、表示或分布。

需要掌握：

- 无监督学习和监督学习的区别。
- 聚类、降维、密度估计、表示学习的任务目标。
- PCA、稀疏编码、自编码器的基本思想。
- 无监督学习结果如何评价。
- 无监督表示怎样服务下游任务。

## 2. 无监督学习做什么

无监督学习面对的数据只有：

```text
{x_1, x_2, ..., x_N}
```

没有标签 `y`。

常见目标：

- 发现数据簇结构。
- 学习低维表示。
- 建模数据分布。
- 生成或重构数据。
- 为监督任务预训练特征。

## 3. 聚类

聚类把相似样本划到同一组。

K-means 思想：

1. 初始化 K 个中心。
2. 把每个样本分配给最近中心。
3. 更新每个中心为簇内样本均值。
4. 重复直到稳定。

聚类依赖相似度度量。不同距离函数和特征表示会得到不同结果。

## 4. 降维

降维把高维数据映射到低维空间：

```text
x in R^D -> z in R^d, d < D
```

目的：

- 去除冗余。
- 降低计算成本。
- 可视化。
- 发现主要变化方向。

## 5. PCA

PCA 寻找方差最大的正交方向，把数据投影到这些方向上。

直觉：

- 最大方差方向保留最多数据变化。
- 低维投影尽量减少重构误差。

PCA 是线性降维方法，适合发现线性结构。对复杂非线性流形，需要更复杂方法。

## 6. 稀疏编码

稀疏编码希望用少量基向量重构输入：

```text
x ≈ D z
```

其中 `D` 是字典，`z` 是稀疏系数。

核心假设：一个样本可以由少数基本模式组合得到。

稀疏性让表示更可解释，也能减少噪声影响。

## 7. 自编码器

自编码器由编码器和解码器组成：

```text
x -> encoder -> z -> decoder -> x_hat
```

训练目标是让重构 `x_hat` 接近输入 `x`。

如果中间表示 `z` 维度较低或受到约束，模型被迫学习压缩表示，而不是简单复制输入。

## 8. 自编码器变体

常见变体：

- 欠完备自编码器：隐藏维度小于输入维度。
- 稀疏自编码器：对隐藏表示加稀疏约束。
- 去噪自编码器：输入加噪声，目标重构干净输入。
- 收缩自编码器：限制表示对输入扰动过于敏感。

不同变体都在避免模型学成恒等映射。

## 9. 密度估计

密度估计试图学习数据分布：

```text
p(x)
```

一旦学到分布，就可以：

- 判断样本是否异常。
- 生成新样本。
- 计算样本似然。
- 学习潜在结构。

深度生成模型可以看成无监督密度建模或隐变量建模的重要方向。

## 10. 表示学习

无监督表示学习的价值在于：用大量无标注数据学习通用特征，再迁移到下游监督任务。

预训练思想：

```text
无标注数据上学表示 -> 有标注数据上微调
```

这条路线在自然语言处理、视觉预训练和多模态模型中非常重要。

## 11. 评价问题

无监督学习没有标准标签，评价更困难。

常见方式：

- 看重构误差。
- 看聚类内部紧密和外部分离程度。
- 看生成样本质量。
- 看下游任务性能。
- 人工可视化和错误分析。

不要只看一个指标，尤其不要把可视化结果当成严格证明。

## 12. 易错点

- 无监督不等于没有目标函数。
- 自编码器重构好不一定表示对下游任务有用。
- PCA 是线性方法，不适合所有非线性结构。
- 聚类结果强烈依赖特征表示和距离度量。
- 无标签不代表没有偏差，数据分布本身可能有偏。
