# 线性模型

## 1. 本章目标

线性模型是神经网络的基础。很多神经网络层本质上先做线性变换，再接非线性激活。

本章要掌握：

- 线性判别函数和决策边界。
- Logistic 回归和 Softmax 回归。
- 感知器与线性可分。
- 支持向量机的最大间隔思想。
- 常见线性模型损失函数的差异。

## 2. 线性函数

基本形式：

```text
f(x) = w^T x + b
```

其中 `w` 控制各特征权重，`b` 控制整体偏移。

线性模型的关键不是“简单”，而是它构成了更复杂模型的基本部件。多层神经网络里的全连接层就是矩阵形式的线性模型：

```text
Y = XW + b
```

## 3. 决策边界

二分类中可以用符号函数做决策：

```text
y_hat = sign(w^T x + b)
```

决策边界是：

```text
w^T x + b = 0
```

在二维空间里是直线，在高维空间里是超平面。线性模型只能直接分开线性可分的数据；如果数据本身非线性可分，需要特征变换、核方法或神经网络。

## 4. 线性回归

线性回归用于连续值预测：

```text
y_hat = w^T x + b
```

常用均方误差：

```text
L = (y - y_hat)^2
```

均方误差对大误差惩罚更重，因此对异常值较敏感。

## 5. Logistic 回归

Logistic 回归用于二分类。它先计算线性得分，再通过 Sigmoid 转成概率：

```text
z = w^T x + b
p(y=1|x) = sigmoid(z)
sigmoid(z) = 1 / (1 + exp(-z))
```

常用交叉熵损失：

```text
L = -y log p - (1-y) log(1-p)
```

Logistic 回归虽然名字里有“回归”，但通常用于分类。它的输出可以解释为类别后验概率。

## 6. Softmax 回归

Softmax 回归是 Logistic 回归的多分类推广。

对每个类别计算一个得分：

```text
z_c = w_c^T x + b_c
```

再转成概率：

```text
p(y=c|x) = exp(z_c) / sum_j exp(z_j)
```

训练时通常使用多分类交叉熵。

Softmax 的作用不是让模型“更深”，而是把多类得分归一化成概率分布。

## 7. 感知器

感知器是最早的线性分类模型之一，可看成单个神经元：

```text
y_hat = sign(w^T x + b)
```

当数据线性可分时，感知器学习算法可以找到一个分离超平面。它的问题是：

- 只适用于线性可分数据。
- 得到的分界面不一定有最大间隔。
- 阶跃函数不可导，不适合深层网络的梯度训练。

## 8. 支持向量机

SVM 的核心思想是最大化分类间隔。它不仅要分对样本，还希望决策边界离最近样本尽可能远。

关键概念：

- 支持向量：离决策边界最近、决定间隔的样本。
- 间隔：分类边界到最近样本的距离。
- 软间隔：允许少量样本违反约束，提高对噪声的容忍。
- 核函数：隐式映射到高维特征空间处理非线性可分问题。

SVM 和 Logistic 回归都能做分类，但优化目标不同。Logistic 回归关注概率建模，SVM 关注分类间隔。

## 9. 损失函数对比

常见分类损失：

- 0-1 损失：是否分类错误，难优化。
- 交叉熵损失：强调概率预测，常用于 Logistic 和 Softmax。
- 感知器损失：只惩罚误分类样本。
- Hinge 损失：要求正确分类并留出间隔。

理解损失函数比背模型更重要。不同损失函数对应不同的学习偏好。

## 10. 线性模型和神经网络的关系

神经网络不是抛弃线性模型，而是在多个线性变换之间加入非线性激活：

```text
x -> Linear -> Activation -> Linear -> Activation -> output
```

如果没有激活函数，多层线性变换仍然等价于一层线性变换。

这也是为什么激活函数是神经网络表达能力的关键。

## 11. 易错点

- Logistic 回归不是回归任务，而是分类模型。
- Softmax 输出概率，但概率校准不一定可靠。
- 线性模型的边界是线性的，但输入特征可以先做非线性变换。
- 多层线性层不加激活函数没有意义。
- SVM 的“支持向量”不是所有训练样本。
