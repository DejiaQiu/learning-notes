# 序列生成模型

## 1. 本章目标

序列生成模型用于按顺序生成离散或连续序列，例如文本、语音、代码和动作序列。

需要掌握：

- 序列概率如何分解。
- N-gram、RNN 语言模型、神经序列模型的关系。
- Seq2Seq 的编码器-解码器结构。
- 搜索解码、教师强制和曝光偏差。
- 困惑度、BLEU 等评价指标的局限。

## 2. 序列概率分解

一个序列可以写成：

```text
y = (y_1, y_2, ..., y_T)
```

根据链式法则：

```text
p(y) = product_t p(y_t | y_1, ..., y_{t-1})
```

序列生成模型的任务就是逐步预测下一个元素的条件分布。

## 3. N-gram 语言模型

N-gram 用最近 `n-1` 个词近似完整历史：

```text
p(y_t | y_1, ..., y_{t-1}) ≈ p(y_t | y_{t-n+1}, ..., y_{t-1})
```

优点：

- 简单直观。
- 可解释。

缺点：

- 长距离依赖建模弱。
- 数据稀疏。
- 不能很好泛化到未见组合。

## 4. 神经语言模型

神经语言模型用向量表示词和上下文。

相比 N-gram：

- 能共享词向量中的相似性。
- 能建模更长上下文。
- 能端到端学习表示。

RNN 语言模型用隐藏状态压缩历史：

```text
h_t = RNN(h_{t-1}, y_{t-1})
p(y_t | history) = softmax(W h_t)
```

Transformer 语言模型用自注意力直接读取上下文。

## 5. 条件序列生成

很多任务需要根据输入生成输出：

```text
x -> y_1, y_2, ..., y_T
```

例如：

- 机器翻译。
- 文本摘要。
- 图像描述。
- 对话生成。
- 语音识别。

这类任务通常建模：

```text
p(y|x) = product_t p(y_t | y_<t, x)
```

## 6. Seq2Seq

Seq2Seq 使用编码器-解码器结构：

```text
输入序列 -> Encoder -> 上下文表示 -> Decoder -> 输出序列
```

编码器把输入压缩成表示，解码器根据表示逐步生成输出。

早期 Seq2Seq 把整个输入压缩成固定向量，长序列效果有限。注意力机制通过让解码器每一步动态读取输入，明显改善了这个问题。

## 7. 教师强制

训练解码器时常使用教师强制：

```text
用真实上一个词作为当前步输入
```

这样训练更稳定，但推理时模型只能使用自己上一步生成的词。

训练和推理条件不一致会导致曝光偏差：早期生成错误可能不断累积。

## 8. 解码搜索

生成时需要从概率分布中选择序列。

常见方法：

- 贪心搜索：每一步选概率最大词。
- Beam Search：保留多个候选序列。
- 采样：按概率随机采样。
- Top-k / Top-p：限制候选集合后采样。

搜索策略会显著影响生成质量、多样性和重复程度。

## 9. 评价指标

语言模型常用困惑度：

```text
perplexity = exp(平均负对数似然)
```

困惑度越低，表示模型对真实序列分配的概率越高。

翻译和摘要常用：

- BLEU：看生成文本和参考答案的 n-gram 重合。
- ROUGE：常用于摘要，关注召回。

这些指标不能完全代表语义质量，需要结合人工评价和任务指标。

## 10. 序列生成的常见问题

常见问题：

- 曝光偏差。
- 重复生成。
- 长序列一致性差。
- 生成内容安全和事实性问题。
- 多样性和准确性的平衡。

不同任务对这些问题的容忍度不同。机器翻译更重视准确性，对话更重视自然性和上下文一致。

## 11. 和前面章节的联系

序列生成综合使用了多个章节的知识：

- 概率分解来自概率建模。
- RNN 和注意力用于条件建模。
- 交叉熵用于最大似然训练。
- Beam Search 属于推理阶段的搜索。
- 强化学习可用于直接优化非可导评价指标。

## 12. 易错点

- 训练损失低不一定生成质量好。
- Beam Search 越大不一定越好，可能降低多样性。
- BLEU 高不一定语义完全正确。
- 教师强制提高训练稳定性，但会带来训练-推理不一致。
- 语言模型预测的是概率分布，不是唯一标准答案。
