# 机器学习概述

## 1. 本章目标

这一章建立机器学习的基本框架。后面所有神经网络模型都可以放回这个框架里理解。

核心问题：

- 什么是样本、特征、标签、模型和参数。
- 机器学习的三个基本要素是什么。
- 损失函数、风险函数和正则化有什么关系。
- 优化算法和学习准则有什么区别。
- 偏差-方差分解怎样解释泛化误差。

## 2. 基本概念

一条训练数据通常写成：

```text
(x, y)
```

其中：

- `x` 是输入，也叫特征向量。
- `y` 是标签或目标输出。
- 一组样本构成数据集。
- 模型 `f(x; theta)` 用参数 `theta` 描述输入到输出的映射。

监督学习中，训练集给出输入和标签；无监督学习中，只有输入；强化学习中，智能体通过行动获得奖励反馈。

## 3. 三个基本要素

机器学习方法可以拆成三件事：

```text
模型 + 学习准则 + 优化算法
```

模型决定能表示什么函数。学习准则决定什么叫“好模型”。优化算法决定怎样在参数空间中找到较好的参数。

这三者不要混淆。比如线性回归是模型，均方误差是学习准则，梯度下降或最小二乘求解是优化方法。

## 4. 模型

模型定义假设空间，也就是可选函数集合。

线性模型：

```text
f(x) = w^T x + b
```

非线性模型可以看成先做特征变换再线性组合：

```text
f(x) = w^T phi(x) + b
```

神经网络的特点是 `phi(x)` 也由模型学习，因此它不是固定特征工程，而是可学习的表示变换。

## 5. 学习准则

损失函数衡量单个样本预测错误：

```text
L(y, f(x; theta))
```

经验风险是训练集上的平均损失：

```text
R_emp(theta) = (1/N) * sum L(y_i, f(x_i; theta))
```

期望风险是对真实数据分布的平均损失，但真实分布未知，因此实际训练时通常最小化经验风险或结构风险。

结构风险加入正则项：

```text
R(theta) = R_emp(theta) + lambda * Omega(theta)
```

正则项用来限制模型复杂度，降低过拟合风险。

## 6. 常见损失函数

回归任务常用：

- 均方误差：对大误差敏感。
- 平均绝对误差：对异常值相对稳健。

分类任务常用：

- 0-1 损失：直观但难优化。
- 交叉熵：可导，适合概率输出。
- Hinge 损失：常见于最大间隔分类。

深度学习里常常不是直接优化评价指标，而是优化一个可导的替代损失。

## 7. 优化算法

优化算法负责调整参数：

```text
theta <- theta - alpha * grad_theta R(theta)
```

其中 `alpha` 是学习率。学习率过大可能震荡甚至发散，过小会收敛慢。

常见优化方式：

- 批量梯度下降：一次使用全部数据。
- 随机梯度下降：一次使用一个样本。
- 小批量梯度下降：一次使用一个 batch，是深度学习常用折中。

## 8. 线性回归作为最小例子

线性回归假设：

```text
y_hat = w^T x + b
```

用均方误差训练：

```text
L = (y - y_hat)^2
```

它体现了机器学习的完整闭环：

```text
选择模型 -> 定义损失 -> 计算梯度 -> 更新参数 -> 在新数据上评估
```

后面更复杂的神经网络也遵循这条主线，只是模型、损失和优化更复杂。

## 9. 泛化与过拟合

训练误差低不等于测试误差低。模型可能只是记住训练样本，而没有学到稳定规律。

过拟合常见原因：

- 模型容量过大。
- 训练数据过少或噪声大。
- 训练轮数过多。
- 数据划分存在泄漏。

常见缓解方法：

- 增加数据或数据增强。
- 正则化。
- 早停。
- 降低模型复杂度。
- 严格划分训练集、验证集、测试集。

## 10. 偏差-方差分解

泛化误差可以从偏差和方差角度理解：

- 偏差高：模型太简单，连训练集都拟合不好。
- 方差高：模型太敏感，训练集表现好但测试集不稳定。

欠拟合通常偏差高，过拟合通常方差高。调模型时要判断当前问题是哪一种，而不是盲目加层或调大学习率。

## 11. 机器学习算法类型

按反馈方式：

- 监督学习：标签明确。
- 无监督学习：发现结构或分布。
- 半监督学习：少量有标注 + 大量无标注。
- 强化学习：从交互奖励中学习策略。

按任务目标：

- 分类。
- 回归。
- 聚类。
- 降维。
- 密度估计。
- 生成。

## 12. 易错点

- 把优化算法当成模型本身。
- 只看训练损失，不看验证集和测试集。
- 认为损失越复杂越好，忽略可优化性。
- 忘记正则项会改变训练目标。
- 没有固定数据划分就比较多个模型。
