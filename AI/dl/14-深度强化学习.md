# 深度强化学习

## 1. 本章目标

深度强化学习把深度网络用于强化学习中的价值函数、策略或模型近似。

需要掌握：

- 强化学习的状态、动作、奖励、策略。
- 马尔可夫决策过程。
- 值函数、动作值函数和 Bellman 方程。
- DQN 如何用神经网络近似 Q 函数。
- 策略梯度和 Actor-Critic 的基本思想。

## 2. 强化学习问题

强化学习研究智能体如何通过与环境交互学习策略。

基本循环：

```text
state -> agent chooses action -> environment returns reward and next state
```

目标不是单步奖励最大，而是长期累计回报最大。

## 3. 基本概念

核心元素：

- 状态 `s`：环境当前信息。
- 动作 `a`：智能体可以执行的行为。
- 奖励 `r`：环境反馈。
- 策略 `pi(a|s)`：给定状态选择动作的规则。
- 回报 `G_t`：从当前时刻开始的折扣累计奖励。
- 折扣因子 `gamma`：控制未来奖励的重要性。

回报：

```text
G_t = r_t + gamma r_{t+1} + gamma^2 r_{t+2} + ...
```

## 4. MDP

马尔可夫决策过程假设未来只依赖当前状态和动作，而不依赖更早历史。

它由以下元素组成：

```text
(S, A, P, R, gamma)
```

其中：

- `S` 是状态空间。
- `A` 是动作空间。
- `P` 是状态转移概率。
- `R` 是奖励函数。
- `gamma` 是折扣因子。

## 5. 值函数

状态值函数：

```text
V^pi(s) = E[G_t | s_t = s]
```

动作值函数：

```text
Q^pi(s, a) = E[G_t | s_t = s, a_t = a]
```

`V` 评估状态好不好，`Q` 评估在某状态下执行某动作好不好。

## 6. Bellman 方程

Bellman 方程把长期回报递归拆成：

```text
当前奖励 + 未来状态价值
```

直觉：

```text
一个状态的价值 = 现在能得到什么 + 以后还能得到什么
```

很多强化学习算法都围绕 Bellman 方程构造目标。

## 7. Q-learning

Q-learning 学习最优动作值函数：

```text
Q(s,a) <- Q(s,a) + alpha * [r + gamma max_a' Q(s',a') - Q(s,a)]
```

方括号中的部分叫 TD 误差，表示当前估计和目标估计的差距。

表格 Q-learning 适合小规模离散状态动作空间。

## 8. DQN

DQN 用神经网络近似 Q 函数：

```text
Q(s, a; theta)
```

关键技术：

- 经验回放：打乱样本相关性，提高数据利用率。
- 目标网络：用延迟更新的网络计算目标，稳定训练。

DQN 把深度学习表示能力和 Q-learning 结合起来，适合高维状态输入。

## 9. 策略梯度

策略梯度直接优化策略参数：

```text
pi(a|s; theta)
```

目标是提高能带来高回报动作的概率。

优点：

- 可以处理连续动作。
- 可以学习随机策略。

缺点：

- 方差较大。
- 样本效率可能低。

## 10. Actor-Critic

Actor-Critic 同时学习：

- Actor：策略，负责选动作。
- Critic：价值函数，负责评价动作或状态。

Critic 给 Actor 提供更稳定的学习信号。

它把基于值函数和基于策略的方法结合起来。

## 11. 探索与利用

强化学习必须在探索和利用之间平衡。

- 探索：尝试未知动作，可能发现更好策略。
- 利用：选择当前认为最好的动作，获得已有收益。

常见方法：

- epsilon-greedy。
- 熵正则。
- 噪声策略。

探索不足会陷入局部策略，探索过多会影响收敛效率。

## 12. 易错点

- 强化学习不是监督学习，没有每一步的标准答案标签。
- 奖励设计会强烈影响学到的行为。
- DQN 不是简单把 Q 表换成神经网络，还需要经验回放和目标网络。
- 高回报不一定代表策略安全或符合真实约束。
- 仿真环境成功不等于真实环境成功。
