# 支持向量机 SVM

## 学习法小结

这一章公式多，但主线很短：找到一个分类边界，并让边界离两类样本尽可能远。

学习顺序：

1. 先理解超平面 $w^\top x + b = 0$。
2. 再理解支持向量和最大间隔。
3. 然后看硬间隔为什么要求太强，软间隔如何允许少量错误。
4. 最后看核函数如何把非线性问题变成高维线性问题。

最小掌握目标：

- 能解释什么是支持向量。
- 能说清楚参数 `C` 控制什么。
- 能解释核函数的直觉作用，不必一开始完整推对偶问题。

自测问题：

- 为什么只靠少数支持向量就能决定分类边界？
- `C` 很大和很小时，模型分别更容易怎样？
- RBF 核适合解决什么类型的问题？

## 1. SVM 是什么

支持向量机（Support Vector Machine，SVM）是一种用于分类和回归的模型，最经典的是二分类。

SVM 的核心思想：

$$
\text{找到一个分类超平面，使两类样本之间的间隔最大}
$$

间隔越大，模型对新样本的泛化能力通常越好。

## 2. 超平面

在二维空间中，分类边界是一条直线。

在三维空间中，分类边界是一个平面。

在更高维空间中，分类边界叫超平面。

形式：

$$
w^\top x + b = 0
$$

分类规则：

$$
w^\top x + b > 0 \Rightarrow \text{正类}
$$

$$
w^\top x + b < 0 \Rightarrow \text{负类}
$$

## 3. 支持向量

支持向量是离分类边界最近的样本点。

特点：

- 它们决定了分类超平面的位置。
- 不是所有样本都直接影响最终边界。
- 删除非支持向量，模型边界可能不变。

## 4. 间隔最大化

SVM 希望分类边界离两类样本都尽可能远。

几何间隔越大，分类边界越稳。

硬间隔 SVM 的目标可以理解为：

$$
\text{在所有样本都分类正确的前提下，让间隔最大}
$$

## 5. 硬间隔 SVM

硬间隔要求所有训练样本都被正确分类。

适用条件：

- 数据线性可分。
- 噪声较少。

缺点：

- 对异常点非常敏感。
- 现实数据中很难完全线性可分。

## 6. 软间隔 SVM

软间隔允许部分样本分类错误或落在间隔内部。

引入松弛变量和惩罚参数 C。

### 6.1 C 的含义

C 控制对分类错误的惩罚强度。

$$
C \text{ 大：更重视训练集分类正确，间隔可能更小，容易过拟合}
$$

$$
C \text{ 小：允许更多错误，间隔更大，泛化可能更好}
$$

## 7. 核函数

核函数用于解决非线性分类问题。

核心思想：

$$
x \mapsto \phi(x)
$$

$$
\text{把原始空间中线性不可分的数据映射到高维空间中，使其线性可分}
$$

核技巧不需要显式计算高维映射，只需要计算样本之间的核函数值。

## 8. 常见核函数

### 8.1 线性核

$$
K(x, z) = x^\top z
$$

适合：

- 特征维度高。
- 数据近似线性可分。
- 文本分类。

### 8.2 多项式核

$$
K(x, z) = (x^\top z + c)^d
$$

适合：

- 存在多项式形式的非线性关系。

参数：

- degree：多项式次数。
- coef0：常数项。

### 8.3 RBF 核

RBF 也叫高斯核。

$$
K(x, z) = \exp\left(-\gamma \lVert x - z \rVert^2\right)
$$

适合：

- 非线性分类。
- 默认常用核函数。

### 8.4 Sigmoid 核

形式类似神经网络中的激活函数。

实际使用相对较少。

## 9. gamma 参数

gamma 控制单个样本影响范围。

$$
\gamma \text{ 大：影响范围小，边界复杂，容易过拟合}
$$

$$
\gamma \text{ 小：影响范围大，边界平滑，可能欠拟合}
$$

RBF 核中 gamma 非常重要。

## 10. SVM 优点

- 在中小规模数据上效果好。
- 高维空间中表现较好。
- 通过核函数处理非线性问题。
- 理论基础扎实。
- 最终模型只和支持向量有关。

## 11. SVM 缺点

- 大规模数据训练较慢。
- 参数 C、gamma、kernel 需要调。
- 对特征缩放敏感。
- 输出概率需要额外校准。
- 模型解释性一般。

## 12. SVR

SVR 是 SVM 的回归版本。

它不是要求预测值完全等于真实值，而是允许一定误差范围。

核心思想：

$$
|y - f(x)| \le \epsilon \Rightarrow \text{不惩罚}
$$

$$
|y - f(x)| > \epsilon \Rightarrow \text{惩罚}
$$

常见参数：

- C
- epsilon
- kernel
- gamma

## 13. 使用注意

SVM 对特征尺度敏感，通常必须标准化：

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

model = Pipeline(
    steps=[
        ("scaler", StandardScaler()),
        ("svc", SVC(kernel="rbf", C=1.0, gamma="scale")),
    ]
)
```

## 14. 调参建议

常见搜索范围：

$$
C \in \{0.1, 1, 10, 100\}
$$

$$
\gamma \in \{0.001, 0.01, 0.1, 1\}
$$

$$
\text{kernel} \in \{\text{linear}, \text{rbf}\}
$$

调参逻辑：

- 训练集和验证集都差：增大 C 或 gamma，增加模型复杂度。
- 训练集好但验证集差：减小 C 或 gamma，降低复杂度。
- 特征很多且稀疏：优先试 linear kernel。

## 15. 记忆重点

- SVM 的目标是最大化间隔。
- 支持向量是离边界最近、决定边界的样本。
- C 控制错误惩罚。
- gamma 控制单个样本影响范围。
- RBF 核常用于非线性分类。
- SVM 一般需要特征标准化。
